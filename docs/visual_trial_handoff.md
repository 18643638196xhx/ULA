# RGB-D 试抬交接：不读取物体真值的控制模式

## 目的与区别

原模式用仿真杯子位置与双指接触判断“抓到了”，再让传统控制试抬。
本模式把它替换为：**VLA 发出闭爪指令 → 暂停 VLA → 传统控制试抬 → 视觉确认杯子跟手上移 → 传统放置**。
闭爪指令只代表“可以试一下”，不能证明抓稳；既没有接触传感器，也没有凭空增加力/电流传感器。

| 环节 | 原接触交接模式 | 新视觉交接模式 |
| --- | --- | --- |
| 接近 | RGB-D 点云与几何规划 | 保持不变 |
| 候选交接 | 双指接触杯子 + 闭爪控制状态 | 连续 3 个动作闭爪控制状态低于阈值 |
| 试抬 | 传统控制向上 5 cm | 保持相同距离、3 段慢速规划 |
| 抓取确认 | 仿真杯子抬升与物理接触 | 试抬前后分割 RGB-D 表面的配准运动 |
| 放置 | 初始点云与当前点云配准，规划放置 | 保持不变 |
| 在线成功终止 | 环境真值成功判断可能提前结束动作 | 整个控制阶段禁用；完成后恢复，仅评分 |

## 视觉确认如何做

1. 在闭爪后、试抬前，保存头部和当前手腕的 RGB-D 帧及相机标定。
2. 用已有检测/分割模块提取杯子点云。先尝试头部视角，必要时用手腕。没有可信基准就不试抬。
3. 用机器人自身末端状态规划向上 5 cm，分 3 段慢速执行并检查末端到位。
4. 从试抬后的 RGB-D 再提取杯子表面，与同一相机试抬前的表面做 ICP。
5. 使用配准后的**同一批参考表面点的位移**，不是直接比较两个分割框的中心，也不是读取杯底真值。
6. 视觉上升至少 3 cm、运动大小为末端位移的 0.5–1.6 倍、运动方向余弦至少 0.8，才允许进入放置。

分割或配准不可信时，先换分割提示重看，再尝试保存的手腕基准与当前手腕的匹配视角。重看期间不额外移动机器人。
所有候选都失败时停止，不释放、不放置。这里没有恢复原来的 1 cm 相对漂移/滑移门槛。

这些是有容差的视觉启发式，不是抓稳的物理证明。遮挡、对称杯身、分割到夹爪、深度噪声仍可能造成误判。

## 真值边界

新增 `--grasp-handoff visual-trial-lift`，仅支持 pointcloud 的 hybrid / grasp-only。

- 本模式不采集初始杯子位姿，也不逐步记录杯子真值高度。
- 候选交接与视觉试抬不调用杯子位姿、功能点、接触列表。
- 接近、VLA、试抬和放置阶段，实例级屏蔽环境 `check_success()`，使其不能用物体真值提前终止动作。异常时也会恢复原方法。
- 完整控制结束后恢复环境评分，允许读取杯子/杯垫功能点计算最终成功与误差；这些结果不反馈给控制器。
- 仍在仿真中使用 RGB-D 渲染、机器人模型及状态、相机标定、配置的桌面碰撞盒。不是已经验证的真机系统。
- 不使用 FoundationPose、预制杯子 CAD 或仿真身份分割；仍假设刚性杯子起始直立放在水平桌面。

原有模式默认行为不变，旧实验不覆盖。新代码位于 `adapters/visual_grasp.py`，调度入口仍为 `scripts/run_place_empty_cup.py`。

## 运行

在 `/data1/xuhuixin/ula` 下运行；每次使用新的输出目录：

```bash
env GPU=5 bash scripts/run_place_empty_cup.sh \
  --mode hybrid --approach-mode pointcloud \
  --pointcloud-multiview --pointcloud-reobserve \
  --grasp-retries 1 --grasp-stall-steps 120 \
  --registration-max-rmse 0.012 --registration-max-tilt 35 \
  --grasp-handoff visual-trial-lift --contact-gripper-threshold 0.05 \
  --episodes 50 --seed 0 --max-vla-steps 500 \
  --output /data1/xuhuixin/ula/results/visual_trial_50eps_run1
```

本模式自动不做旧滑移检查，不需要 `--skip-trial-slip-check`。
`--contact-gripper-threshold` 沿用原参数名，但在这里仅是闭爪**控制状态**阈值，不是测得的夹爪开度或接触阈值。

重点检查每轮 `candidate_handoff.json`、`result.json` 中的 `traditional_grasp_verification`（前后观测、配准、跟手位移证据），以及 `report.json` 中统计。
成功率必须计入所有失败；完成时间仅对成功样本求均值，并另报全部尝试耗时。排除第一轮的统计口径与旧实验保持一致。

## 2026-10-24 实验结果

先导 3 次（seeds 0–2）全部成功，随后保持控制配置进行完整 50 次实验。
完整结果位于 `/data1/xuhuixin/ula/results/visual_trial_50eps_20261024_v1/report.json`。
同一模型与任务、demo_clean、固定左臂、默认光栅渲染、GPU 5、seeds 0–49；配准门槛仍为 12 mm / 35°，只改变交接模式及在线真值终止边界。

### 交接与失败情况

- 50/50 通过视觉试抬交接，50/50 执行完传统放置动作，但只有 49/50 满足最终任务评分。
- 46 次使用头部匹配视角完成视觉验证，4 次使用匹配的腕部试抬前/后画面。
- 估计的可见杯身表面上升量为 4.13–6.14 cm。这不是杯底真值位移。
- 本批次没有触发抓取重试。感知进程仅启动 1 次；245 个请求中 237 个成功返回，其余请求错误由有界重观测路径处理，没有隐式重载模型。
- 唯一失败是 **seed 30**：视觉试抬估计上移 5.017 cm，末端实际上移 4.998 cm，视觉交接通过；搬运/放置动作也完成。但最终评分测得杯子与杯垫功能点水平误差 **4.165 cm**，超过 **3.5 cm** 门槛；竖直误差 0.830 cm，在 1.5 cm 门槛内。已确认的直接失败条件是最终水平放置偏差超限，不是视觉试抬/ICP 拒绝；偏差的具体来源仍需另行定位。

本轮支持“无需在线物体位姿/接触真值，也可以完成该固定设置下的交接”的可行性结论；不代表已证明对所有未知杯子或真机可靠。

验证：117 项单元测试通过，包含控制阶段禁止杯子位姿/接触访问、禁止真值在线终止、异常恢复、空抓拒绝、无可信基准不移动、腕部匹配前后视角，以及完整批次最终评分隔离测试。
