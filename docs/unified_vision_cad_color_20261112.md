# CAD 颜色核验复验

本轮仅添加可选的 `VisionConfig.verify_cad_color`，默认关闭。使用调用者提供的静态 CAD 纹理，不读取仿真物体颜色标签、位姿或评分掩码。没有真实 UV 纹理时跳过，不能将渲染器生成的默认材质作为颜色参考。

几何通过后，取候选分割内、渲染深度与测量深度相差不超过既有深度门槛的像素，比较实拍与渲染的 RGB 色度分布。归一化 RGB 降低整体亮度变化影响；12×12 直方图以 0.8 格高斯平滑容忍轻微颜色偏移。此实现仍不具备严格光照不变性。

双方各至少 40 个有效彩色像素时，以分布重合度 0.35 为本轮预先固定的试验门槛。暗区、低饱和度区域或证据不足记为 unobservable，不据此拒绝。明确颜色矛盾才淘汰候选；颜色一致不等于身份证明，也不自动解除位姿歧义。未调低 CAD 几何核验门槛。上述颜色门槛是待验证超参数，不是通用性结论。

复验使用与上一轮相同的 4 个任务、每任务 2 场保存的头部 RGB-D。输出为 `results/unified_vision_robust_geometry_color_replay8_20261112_v1/report.json`，只代表初始定位，不代表完整任务成功率。与最近 v2 的 6/8 对照；旧归档的 7/8 包含其他算法差异，不能作为颜色的单因素对照。

针对颜色与已有 CAD/稳健几何代码的测试：47 passed。覆盖亮度缩放、异色拒绝、无彩色证据不拒绝、掩码外背景不参与和默认关闭。
