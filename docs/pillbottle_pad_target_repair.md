# 已知模型药瓶：修复遮挡下的错误垫子目标

## 问题和范围

v21 的 seed 5、43 初始语义分割给出的垫子高度分别约 0.894 m、0.954 m，与约 0.741 m 的视觉桌面矛盾。该错误目标被缓存并用于传统放置。只增加抓后腕部瓶身定位无法修复初始目标；改为连续 VLA 放置的 v22 两轮也都失败。

本次仅在已知模型药瓶的 `annotated + visual` 分支加入目标校验与恢复。保留传统接近、VLA 抓取、传统搬运放置、不试抬，以及原运动、配准、释放门槛。杯子、微波炉、原无模型药瓶、RoboTwin 和 VLA 源码未改。

## 实现

1. 将初始垫子估计高度与本轮 RGB-D 估计的桌面高度比较。差值超过 1 cm 或坐标无效时，不允许该目标进入规划。不是把旧目标的 Z 值强行改成桌面高度。
2. 使用实际 RGB-D 里的蓝色区域恢复目标。只保留距视觉桌面不超过 1 cm 的有效深度点，去掉像素数不足 5 的蓝色噪点连通片；遮挡可能把垫子分成几条不连通的可见条带，因此保留多个受支持片段。
3. 从头部相机开始；观测范围不足时，依次加入左腕、右腕相机的当前点云，使用各自标定变换到世界坐标。不额外移动机械臂，不把旧深度伪装成新测量。
4. 在水平面上拟合实测点的最小面积矩形。两边均需在 2.5–15 cm 之间、短长边比至少 0.75；不完整窄条拒绝，不假设已看到了隐藏边界。中心取实测范围中心，高度取所用蓝色点的中位数，再过桌面高度检查。
5. 仅在恢复成功后，更新本轮的选定参考文件、缓存垫子目标和接近审计。均失败则在接近前停止。原先高度合理的语义目标不被此回退替换。

这增加了明确任务先验：**单一蓝色、水平、近似方形垫子，可见范围近似覆盖两条轴向边界**。没有读取垫子 CAD、尺寸标注或实时仿真位姿。颜色差阈值为归一化 B 分量超过 0.25 且分别大于 R、G 至少 0.15；不是通用任意颜色目标分割，也未验证随机光照、多蓝色物体或完全遮挡。拟合出的矩形不保证隐藏真实边界被完全观测到；不能把近似中心当作无误差测量。

目标恢复审计存于 `handoff.pad_target_validation` 和 `traditional_placement.pad_target_validation`。实现位于 `adapters/pillbottle_pad_target.py`、`KnownPerception.resolve_initial_pad`；报告实现指纹包含新模块。
