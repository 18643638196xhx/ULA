# 50 任务示范交接范围初测

输入是 `demo_clean` 每个任务的 `episode_0000000.hdf5`，共 50 条。仅读取机器人状态和相机 RGB，不读取在线物体真值。

统一规则：找到夹爪最终闭到 0 附近的第一段连续变化；排除只闭到半开的准备动作。以这段变化开始前的机器人手位姿为局部操作参考，从此前轨迹中找距离参考位姿 5–12 cm、最接近 8 cm 的已记录位姿，作为传统控制与 VLA 的候选交接点。这里比较的是两个机器人手位姿，不是手到物体表面的距离。

结果：49/50 个任务提取到候选位姿。`turn_switch` 在第 1 帧就开始闭爪，之前手部位移不足，因此不能靠这次闭爪确定交接点。`click_alarmclock` 和 `press_stapler` 提取成功；示范在交接点到闭爪间分别转腕约 26.5° 和 25.0°，这段旋转应留在局部动作里，不应用 15° 门槛拒绝。15° 的建议门槛仅用于执行时比较实际机器人手朝向与示范交接朝向。

`adjust_bottle` 提取左手第 40 帧，距闭爪前机器人手约 7.9 cm。`place_empty_cup` 提取右手第 63 帧，闭爪起点第 75 帧。59 个手臂候选的交接点领先闭爪起点 10–26 帧，中位数 20 帧（示范采样 15 Hz）。

结果文件：`results/demo_handoff_50_20261112_v2/report.json` 和 `summary.csv`。脚本：`scripts/audit_demo_handoff_50.py`。

这一步只证明示范中存在这样的机器人手位姿，而且示范曾经过该位姿。HDF5 不含深度或物体三维位姿，尚不能计算“相对目标物体”的交接位姿，也没有验证新场景中视觉定位、避障规划、实际到位或 VLA 从该状态继续操作。后续必须在示范时记录目标物体的视觉三维位姿，再以同样的物体坐标系生成新场景目标；之后逐任务做传统控制的规划与实际到位评测。
