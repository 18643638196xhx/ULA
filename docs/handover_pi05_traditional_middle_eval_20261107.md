# pi0.5 抓起后接传统搬运：中间交接区阶段评测

本轮只测试：初始 RGB-D 定位 → 原传统接近 → 10000 步原生 pi0.5 抓起并保持 → 传统控制搬到中间交接区。
不执行右手接取、左手释放和最终平台放置，不恢复训练，不修改杯子、药瓶、微波炉或旧五段交接实验代码。

## 与上一轮保持一致的部分

继续使用相同的 10000 步检查点、训练时的抓取指令、三路 RGB 和命令关节状态、检查点自身归一化资产、10 动作重规划块、每场景固定推理随机种子和 200 个 VLA 动作预算。
不使用“空手抬高 8 cm”提前结束，也不在搬运前增加传统试抬或额外固定 10 cm 抬升。
仍从 seed 20000 开始生成 50 个有效随机场景，初始化失败单列并补足；定位或接近失败留在总体分母。
由于新增的搬运规划可能影响后续规划器内部状态，不能预设重跑的每一个接近动作都与旧轮逐位相同，应核对相同 seed 的实际阶段结果。

## 传统控制怎么计算搬运目标

搬运目标采用官方动作中间位置对应的直立红块中心 `[0,0,1.0] m`，底部功能点对应 `[0,0,0.9] m`。这是任务预设的交接位置，不是读取当前物体真值。

不能将“VLA 已经抬升后的手位置”与“抓前仍在桌面的红块位置”直接绑定；那会把已经发生的抬升丢掉。
本轮从 VLA 的机器人命令记录中找到最后一段持续闭爪（控制值 <0.05、至少 3 个动作）的起点，用该时刻手的实际位姿与初始 RGB-D 估计的红块位姿建立手—物体相对关系。
之后通过手的实际运动更新预测红块位置和朝向，反算红块中心到达中间目标、红块长轴保持直立时手应该到达的位姿，并由 CuRobo 规划执行。

这里仍然有明确假设：**红块在闭爪前没有明显离开初始视觉位姿，抓后相对手刚性固定**。
没有进行新的抓后点云定位，也没有用真值修正这个关联。若 VLA 提前碰倒、推移红块，或者实际夹持发生滑动，预测就可能失准；独立评分会暴露这些误差。

接管只使用机器人闭爪历史，不用独立抓起真值决定是否搬运。
即使某轮实际上没有抓到，只要机器人命令允许，控制器仍会尝试搬运；这些样本的动作记录保留，但不能算入“已经抓起后的搬运成功”分子。

## 固定成功标准

官方任务没有给这个单独中间阶段定义评分，因此本轮在运行前固定以下几何标准，不称为 RoboTwin 官方成功率：

- 红块真实中心距 `[0,0,1.0] m` 不超过 **5 cm**。
- 红块长轴相对世界竖直方向倾斜不超过 **15°**。
- 到位后执行固定 5 段保持，每段 15 个物理步，共约 0.3 s。五次采样中红块整体均比初始最低面高至少 3 cm，靠近闭合左手，手—物体相对平移漂移不超过 2 cm。
- 同时报告更严格的 **3 cm** 中心误差结果、实际位置误差、底部功能点误差与倾斜角。

这属于几何抓持核验，不是夹持力或物理接触证明。
物体真值只进入被动评分，既不输入 pi0.5，也不提供给传统规划、接管门槛或重规划逻辑。

还会单独记录机械臂的规划执行状态与手的到位误差，不能用它们代替“红块实际到位”。

## 如何计算成功率

总体通过率：完成接近、抓起和中间搬运的次数 / 50 个有效场景。

抓起后的传统搬运成功率：抓起且中间搬运成功的次数 / **搬运前独立核验确实抓起的次数**。

同时保留“机器人命令允许并实际尝试搬运”的次数和“规划执行完成”的次数。它们可能包含空抓，不应直接冒充搬运真实物体的成功率。

## 本轮结果

运行完成：seed 20000–20056 共 57 次尝试，其中 7 次环境初始化失败单列，得到 50 个有效随机场景。

| 阶段指标 | 结果 |
| --- | ---: |
| 红块定位有输出 | 24/50 |
| 传统接近成功并进入 pi0.5 | 23/50 |
| 独立核验抓起成功 | 21/23 |
| 抓起后传统搬运到区成功率 | **21/21，100%** |
| 更严格 3 cm 到位标准 | **21/21，100%** |
| 从初始状态到中间区域的总体通过率 | **21/50，42%** |
| 搬运规划执行完成（包含空抓） | 23/23 |

50 个有效 seed 与上一轮抓起评测全部对应，逐 seed 的抓起成功/失败结果也一致。
26 次失败发生在定位阶段、1 次在传统接近阶段、2 次（20047、20049）在抓起阶段。
这两个未抓起样本也按机器人闭爪命令尝试了搬运，说明没有用真值先筛掉空抓；但红块实际未被送到交接区，不算成功。

21 次真实抓起后的搬运没有新增失败。红块最终中心误差平均 **5.53 mm**、最大 **9.36 mm**，最大倾斜约 **1.29°**。
用于搬运的闭爪关联在抓起终态的独立位置核验误差最大约 **7.28 mm**，但这不代表该近似对发生提前推移、倾倒或滑动的其他情况也可靠。

本轮只验证几何搬运到位和短时几何持握，不验证右手视觉条件、右手接住、左手释放或最终放置。
抽查 seed 20001 的搬运后三路画面，红块不易看清；本轮没有将“右手是否看得清、能否接取”纳入评分。下一阶段需要单独验证，不能把中间到位的 100% 当作完整交接成功率。
