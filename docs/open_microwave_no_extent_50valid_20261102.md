# 微波炉：取消抓后门板固定尺寸检查

## 本次改动的边界

用户要求在上一批动态排序方案基础上取消门板尺寸检查，再测成功率。本次采用独立入口，不覆盖旧结果、不改写原代码。

唯一控制判定变化是：抓后门板跟踪的两次平面拟合，不再要求可见面片宽、高处于 **8–90 cm**。尺寸仍正常计算并保存，但不据此拒绝该面片。初始视觉定位仍采用原有尺寸规则，不影响初始目标和门轴定义。

仍保留：当前深度、至少 80 个跟踪点、RANSAC 支持率、二维表面分布、平面残差、法向搜索范围、视觉门轴一致性、初始范围约束、相对可见面积比例，以及每一步必须有可信正向开门进度。路径规划、机器人到位、VLA 闭爪接管、失败停止策略都不变。因此这是**取消固定宽高门槛**，不是取消所有视觉反馈，也不是不顾观测继续盲拉。

沿用上一批的几何候选、IK 动态排序和分级规划预算，没有固定优先 10° 或 20°。没有额外试抬或试拉，没有 VLA 开门回退，没有 CAD/物体真值控制。

## 验证和设置

新增 5 项 CPU 单测：正常尺寸时新旧拟合结果逐项完全一致；6 cm 高面片旧代码拒绝而新代码可通过；缺深度和退化线段仍拒绝；只在跟踪调用内替换拟合，不改初始定位；异常后恢复原函数。

使用 `demo_randomized` 场景与固定指令，seed 0 起连续尝试，填满 50 个正常初始化的场景。初始化拒绝单独记录并补足；机器人执行后的失败全部保留在方法成功率分母。完整成功要求控制器正常完成且官方评分通过，另列官方评分。平均完成时间只取成功样本，排除首个有效场景。

GPU 7 主进程、GPU 6 视觉；两者均共享、未隔离算力，JAX platform allocator 与上一批相同。模型与视觉 worker 在整批内复用。官方评分及门关节仅在控制结束后读取作评价，不回传动作。

```bash
cd /data1/xuhuixin/ula
GPU=7 XLA_PYTHON_CLIENT_ALLOCATOR=platform \
MAX_JOBS=2 OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
bash scripts/run_open_microwave_no_extent_randomized.sh \
  --mode hybrid --episodes 50 --seed 0 --vision-gpu 6 \
  --approach-clearance 0.025 --approach-gripper 0.45 \
  --max-vla-steps 100 --target-angle-deg 70 \
  --output /data1/xuhuixin/ula/results/microwave_no_extent_randomized_50valid_seed0_20261102_v1 \
  > /data1/xuhuixin/ula/results/microwave_no_extent_randomized_50valid_seed0_20261102_v1.launcher.log 2>&1
```

复现请另选空目录。根目录 `report.json` 保存全部尝试、有效计数、初始化拒绝、每轮候选/运动/视觉审计、阶段计时、禁用与保留的检查、源文件哈希和视觉进程关闭状态。

已结束，`run_status=finished`、`completed_valid_episodes=50`。连续尝试 seeds 0–60，共 61 次原始尝试；11 次初始化拒绝，与上一批相同，均排除并补足。拒绝 seeds 为 10、14、27、31、37、38、39、45、49、53、55。比较的是同一组 50 个有效场景，不是从中挑选成功样本。

| 指标 | 动态排序，保留固定尺寸检查 | 本批取消固定尺寸检查 |
| --- | --- | --- |
| 完整流程成功率 | 52%（26/50） | **68%（34/50）** |
| 官方评分成功率 | 62%（31/50） | **72%（36/50）** |

本批首个有效场景 seed 0 成功，剔除它之后有 33 个成功样本进入平均完成时间。上一批 seed 0 失败，成功时间样本为 26 个；因此两批成功完成均时的样本集合不同。成功率保留所有 50 个有效场景。

333 项全量 CPU 回归通过。初始感知、接近排序、VLA 接管和开门运动策略未改变。本批 36 个通过初始视觉的场景均完成接近；35 对剔除首轮后的共同接近样本，旧均时 2.1287 s、本批 2.1263 s，接近提速没有因为这次变化而丢失。共享 GPU 没有算力隔离。

## 恢复了哪些样本

上一批的 26 个完整成功全部保留，没有新增退化。新增完整成功为 **0、5、15、23、35、36、40、44**，共 8 次。

对上一批比原始直接拉门新增失败的 7 个 seed，逐条核对如下：

| seed | 本批完整结果 | 本批官方评分 |
| --- | --- | --- |
| 0 | 成功 | 通过 |
| 15 | 成功 | 通过 |
| 30 | 仍失败 | 通过 |
| 35 | 成功 | 通过 |
| 36 | 成功 | 通过 |
| 40 | 成功 | 通过 |
| 44 | 成功 | 通过 |

因此 7 个中的 **6 个恢复**，不是 7 个全部恢复。运行中的一条进度消息曾误将 seed 30 报为恢复，随后已纠正；以此处和逐轮报告为准。

本批共接受 13 个宽或高不足 8 cm 的抓后门板观测，它们仍经过其余平面和跟踪判据。seed 0 的接受观测最低高度约 7.68 cm，seed 15 约 7.88 cm，最终都完整成功，说明这批确实使用了原固定尺寸门槛会拒绝的观测。

seed 40 上一批触发的是负角度增量，这次正向进度门槛并没有取消，本次最后接受的视觉角约 69.38°、增量约 0.709°，因而正常完成。两次实际观测序列不完全一致，不能将它的恢复直接解释为“负增量检查被绕过”，也不能把 8 个恢复都看作严格相同动作序列下单个判据的因果证明。

## 剩余两次开门失败

| --- | --- | --- | --- | --- |
| 28 | 66.39° | 无可靠竖直门面平面 | 相对初始范围的面片面积比例未过 | 通过 |
| 30 | 66.66° | 无可靠竖直门面平面／平面支持不足 | 相对初始范围的面片面积比例未过 | 通过 |

两次均在第 27 段开门动作后的观测中停止。它们**不是固定宽高尺寸检查失败**，因为这道检查已经不执行。当前保留的相对面积判据仍要求面片面积为初始范围的 20%–140%；保存的拒绝文字没有记录当时具体面积比例，不能仅凭该文字断言一定是低于 20%，而非超出上限。本批没有继续取消这一判据或放宽其他条件。

另有 14 次失败仍在初始视觉定位：1、3、4、7、9、18、19、20、24、43、46、50、52、57，均未进入 VLA，和上一批一致。两次开门失败最终官方评分均通过，所以官方通过数比完整成功多 2 次。

## 一致性与结论

`randomized_sources_unchanged=true`、`placement_files_unchanged_during_run=true`；对照上一批记录的全部原有源码哈希，无差异。视觉 worker 整批启动一次，最终 `closed=true`、`running=false`；主进程已退出。退出码 1 表示批次存在失败轮次，不表示没跑完。原结果、原控制器和其他任务没有覆盖。

结论：在本批随机场景中，仅取消抓后固定宽高门槛，使完整成功 26→34、官方通过 31→36，保留了快速接近。它支持原门槛会因局部可见面片而过早拒绝部分正常操作，但不证明所有视觉检查都可以删除，也不构成跨任务或实机泛化验证。
