# pi0.5 10000 步：只测左手抓起红块

按用户要求评测已保存的 10000 步原生 pi0.5 LoRA，不恢复或继续训练，不使用 12000 步模型。
本轮不执行中间搬运、双手交接、平台放置，也不加入传统试抬。

## 固定设置

- 检查点：`/data1/xuhuixin/ula/checkpoints/pi05_handover_pickup50_10000_4gpu_20261107_v1/checkpoints/10000`。
- 任务：`handover_block`，`demo_randomized`。
- 从 seed 20000 顺序生成 50 个初始化正常的随机场景。环境初始化拒绝的 seed 单列并补足有效场景；定位或接近失败仍计入总体分母。
- 已检查与采集阶段所有尝试 seed（包括未收录的尝试）无交集。
- 仍用原有 RGB-D 红块定位、已知 6×6×20 cm 长方体几何和传统 7 cm 预抓取接近。不要求杯垫/平台定位成功。
- 只使用原生 pi0.5，不加载 WorldLA 模型、阶段路由器、消息适配器或 WAM。
- 语言与训练完全相同：`Pick up the red block with the left arm and hold it above the table.`
- 三路 RGB、机器人命令状态和语言输入；加载该检查点自己的训练集归一化资产。
- 每次预测 50 个 14 维动作，执行前 10 个后重新观测。采用原生新动作块执行，不做旧 WorldLA 的 tail blend。
- 每轮最多执行 200 个 VLA 动作。不再因闭爪或手抬高 8 cm 提前结束；没有额外传统抬升动作。
- 推理随机种子固定为 20261107，每个场景独立重置，避免前一场景定位失败改变后续随机序列。

## 独立评分

沿用上一轮 `PickupAudit`：按红块仿真姿态算最低表面，整体相对初始最低面上升至少 3 cm，连续 5 个动作采样满足；左手控制值仍闭合、红块中心距左手 TCP 不超过 20 cm，窗口内物体相对手的平移漂移不超过 2 cm；停止时仍保持抬升、靠近闭合左手。
这属于几何抓起判据，不是力或接触证明。仿真真值只进入被动评分，不提供给模型、几何规划、停止条件或动作选择。

分别报告：

1. 全部 50 个初始化正常场景中的总体抓起率。
2. 实际进入 pi0.5 后的条件抓起率。
3. 定位无输出、接近不到位、抓起未通过等数量，以及曾短暂满足抓起但最终未保持的情况。

本轮相对之前的 1/50 除训练模型外还改变了随机场景、语言、停止规则与动作块执行方式，因此不能将两个百分比差值全部归为训练收益。严格归因需要相同新协议下再做匹配的未训练模型对照。

## 已完成的结果

seed 20000–20056 共尝试 57 个场景，其中 7 次环境初始化拒绝，不进入方法评测分母；顺延得到 50 个有效随机场景。

| --- | ---: |

| 红块定位有可信输出 | 24/50，48% |

| 定位无可信输出 | 26 次 |
| 传统接近不到位 | 1 次，seed 20029 |
| 进入 pi0.5 后抓起未通过 | 2 次，seed 20047、20049 |

所有进入 pi0.5 的轮次都执行了完整 200 个动作，没有空手抬高提前终止或模型执行异常。
21 次曾满足连续抓起判据的样本，在最终也均保持抬起，没有“曾成功抓起但末态掉落”的额外失败。
seed 20047、20049 的红块最低面最大抬升均不足 1 mm，未达到整体离桌 3 cm；不是因为相对漂移门槛拒绝了已经拿起的红块。

独立核验仍只用于评分。抽查 seed 20001、20043 的最终头部画面与抓起记录一致。
本轮失败主要集中在 pi0.5 接管之前的定位环节，但不能把 23 次条件样本的 91.30% 解读为任意场景或完整交接任务都有该成功率。
