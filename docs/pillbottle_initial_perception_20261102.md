# 药瓶随机场景：单独测试初始感知与定位

本实验只回答“机器人开始抓取前，能否找对药瓶、垫子并得到可接受的药瓶 CAD 位姿”。不接近、不抓取、不试抬、不搬运放置，不加载 VLA，也不调用任务成功评分。因此本页的比例不是完整任务成功率，不涵盖抓后遮挡下的定位。

沿用药瓶新迁移的杯子方法：橙白药瓶/蓝色方垫的颜色、深度、语义前端，随后使用杯子原有的全局 FoundationPose 注册、CAD 深度一致性和桌面检查。固定预配置 `080_pillbottle/base1`，不根据场景对象真值选择模型。相机输入只有 RGB、深度、内参、外参；不以仿真对象标签过滤输入。正式控制流程文件没有改动，独立工作进程仅加记录钩子，保留被拒绝的中间结果。

从 seed 0 连续生成随机场景，目标是 50 个成功初始化的场景。初始化被 RoboTwin 拒绝时单独记录，再使用下一个 seed 补足；初始化成功后的感知拒绝全部计入分母。场景保留随机杂物、背景、光照和桌面高度。相机只使用初始头部 RGB-D，不主动改变机械臂视角。

## 统计口径

“识别输出”表示前端接受了对应目标；“CAD 定位通过”表示本方法原有 CAD 检查通过，并不自动证明认对。原前端先处理垫子；若垫子识别失败，后面的药瓶识别尚未执行，必须注明是未进入，不将它描述为已确认药瓶识别错误。

每轮先把预测写入文件，再独立读取同一帧的渲染身份标签，核验预测像素是否属于目标。实际输出的是经腐蚀、深度筛选后的可见表面，不能仅因整物体掩码 IoU 较低就称“认错物体”。本实验同时记录 IoU、精度和覆盖率；“目标匹配”采用至少 20 个目标像素且预测像素中至少 80% 属于目标。这个阈值只用于统计，不影响感知候选选择。

CAD 位姿得到后，再独立比较药瓶 CAD 原点的三维位置误差，以及垫子中心的水平误差。两者均不超过 2 cm、且两个目标身份都匹配时，记为“定位经核验”。这也是独立评测口径，不是新加的控制门槛；旋转精度不包含在此通过率中。真值核验后不再进行推理、重选或规划。

## 输出与复现

输出目录：`results/pillbottle_initial_cup_method_randomized_50valid_seed0_20261102_v1/`。

每轮保存原始画面、RGB-D、冻结的预测、预测覆盖图、真值轮廓对照图和独立核验记录。汇总在 `report.json`，结束后生成 `contact_sheet_*.png`。原图与核验图都保留，彩色覆盖并非相机原始颜色。

