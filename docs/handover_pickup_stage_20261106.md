# handover_block：仅评测左手抓起红块

本实验独立于五段完整任务，不修改已有杯子、药瓶、微波炉或交接控制代码。

## 目的与流程

先确认红块能否真正被抓起，再讨论中间搬运、双手交接和最终放置。
只运行：初始 RGB-D 定位红块 → 原有传统接近 → VLA 左手抓取并抬升 → 停止。
杯垫定位即使失败，也不阻止本阶段。仍沿用原有已知长方体尺寸和几何筛选；未针对本批结果调整感知参数。

不能把三次闭爪指令算作抓起。因此本次不在原闭爪交接点截断 VLA，也不插入传统试抬。
VLA 指令改为仅用左手抓起、抬离桌面并保持，不交接、不放置。
这不是与原五段流程严格只改一个变量的消融，而是独立的阶段能力诊断。

## 何时停止机器人

闭爪指令小于 0.05 后，记录左手 TCP 高度；若重新张开，重置该参考。
左手继续闭合并比该参考上升至少 8 cm，连续满足 5 个动作后停止；最多执行 200 个 VLA 动作。
这个条件只表示手完成了抬升动作，**不代表红块抓取成功**。
控制器不读取红块仿真位姿、接触或下面的评测结果，也不因真值评分成功而提前停下。

## 独立评测

被动记录仿真红块姿态与机器人实际 TCP，不将结果回传控制。
红块为 6×6×20 cm 长方体，按姿态计算整个红块最低表面，不能只看中心高度：倾倒或旋转会使中心改变，但未必离桌。
以初始化后红块最低表面为基准，要求其整体上升至少 3 cm，连续 5 个动作采样成立；同时左手仍给出闭合指令、TCP 距红块中心不超过 20 cm，且这个窗口内红块相对手的位置漂移不超过 2 cm。
终止时红块还须保持上述抬升高度、靠近左手且左手闭合，避免把曾短暂拿起、最后又掉落算作成功。
这是几何持握评测，不是夹持力或物理接触证明；没有用真值完成抓取或规划。

## 样本和输出

从 seed 0 开始，测 50 个初始化正常的随机场景。初始化被环境拒绝的 seed 单列并顺延补足，不进入方法成功率分母。
定位失败和传统接近不到位都计入总体分母，同时给出实际进入 VLA 的条件抓取成功率。
因此可以区分“找不到目标”“没走到接近位置”和“到了以后仍抓不起来”。

每轮保存初始、接近后、最终三路相机画面；若曾满足独立抓起判据，额外保存首次通过时的三路画面。
逐动作独立评测数据位于各轮 result.json 的 evaluation_only，运行汇总持续写入 report.json。

```bash
cd /data1/xuhuixin/ula
GPU=7 HANDOVER_VISION_GPU=6 XLA_PYTHON_CLIENT_ALLOCATOR=platform \
MAX_JOBS=2 OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
bash scripts/run_handover_pickup_randomized.sh \
  --episodes 50 --seed 0 \
  --output /data1/xuhuixin/ula/results/handover_pickup_randomized_50valid_seed0_20261106_v1
```

输出目录非空时拒绝覆盖；复测请更换目录。

## 本轮结果

运行已完成：seed 0–49，共 50 个有效随机场景，初始化拒绝 0 次。
运行期间来源文件哈希未变化，持久感知工作进程已关闭，模型与外部源码未修改。

| 阶段 | 数量 |
| --- | ---: |
| 红块定位有输出 | 25/50 |
| 传统接近到位、实际进入 VLA | 24/50 |
| 独立核验抓起成功 | 1/50，2% |
| 进入 VLA 后的条件抓起率 | 1/24，4.17% |

失败分布：25 次定位无有效输出，1 次传统接近未到位（seed 1），23 次执行 VLA 后未满足抓起判据。
23 次后者中，19 次红块最低面最大上升不足 1 mm；另 4 次最高分别约 0.60 cm（seed 9）、2.52 cm（16）、0.60 cm（22）、1.16 cm（33）。
因此本批失败并非因为“持续 5 步”或相对位移稳定门槛过严：这些样本连整体离桌 3 cm 都未达到。

唯一成功是 seed 45，末态最低面比初始上升约 10.05 cm，保持靠近闭合左手，最后窗口相对位置漂移约 0.034 mm。
已保存并人工抽查末态头部图像。它满足本实验几何抓起标准，不等于已证明能可靠交接。

24 次 VLA 中，19 次因机器人手完成闭合抬升动作而停止，5 次耗尽 200 动作预算。
这再次表明“闭爪并抬手”不能代替“目标确实随手抬起”。
结果只描述**当前传统接近位置、阶段指令与机器人状态停止规则下的 ULA 接入**，不能据此断言 VLA 在其他起点或完整任务指令下也只有相同能力。
没有为了获得更高结果继续接回完整交接流程，也没有在测试过程中调整阈值。
