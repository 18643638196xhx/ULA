# 统一视觉定位：前三项通用修复

日期：2026-11-10。范围仅为深度输入、多实例联合分配、候选保留与有限恢复。没有修改运动控制、细结构清理或 CAD 接受门槛，没有重新执行 50 任务 × 50 场的完整评测。

## 1. 修正深度输入

`get_rgbd()` 和批量 `get_depth()` 共用 `geometric_depth_mm()`。深度直接由相机 Position 几何缓冲区计算；Position 的有效性标志及有限、正深度共同决定有效像素，无效像素置零。RGB 透明度不再改变距离，也不作为几何有效性标志。

这是仿真相机提供的 RGB-D 传感输入，不是读取物体位置、物体身份或接触真值；也不意味着已经模拟了真实深度相机对透明物体的所有测量特性。

同一 `lift_pot / seed 0` 场景，修复前后 RGB 逐像素相同。独立使用事后目标掩码检查，锅的可见高度跨度从错误的 **40.35 cm** 恢复到 **9.33 cm**。该掩码仅用于独立核验，不传给视觉算法。

## 2. 多实例联合分配

同一依赖层的目标先收集当前候选，再统一做实例去重和一对一匹配，之后才解析依赖这些主体的部件。不同目标不能重复占用同一个实例。

例如两个完全相同的碗，不再分别要求“从两个碗中唯一选出一个”。系统允许得到两个不同位置的碗，并将它们分配给两个可互换的输出槽。槽名不代表恢复了仿真内部的物体编号；输出的 `assignment.slot_is_semantic_identity` 明确为 `false`。

不同 CAD、描述或约束的目标，联合比较各自的匹配质量。如果不同分配仍接近，则保留歧义，不强选。实例数量不足时明确返回缺失，不复制已有目标。已有轨迹的目标仍需通过当前观测与历史位置的一致性检查，不能借可互换槽位跳到其他物体上。单目标请求保留原来的唯一性检查。

相同查询内容的单视角分割结果可以复用；同帧、同模型、同掩码的 CAD 检查在一次请求内复用，避免相同物体槽位反复注册相同候选。

## 3. 保留更多候选，有限恢复漏检

首轮仍是默认最多 4 个掩码。恢复轮默认最多处理 8 个去重区域、保留 12 个分割候选；每个区域最多保留 3 个 SAM 分割方案。先让不同区域各保留一个方案，再补同一区域的其他方案，避免候选预算全被一个框占满。

提供 CAD 时，首轮与恢复轮中不同的有效候选一起保留。新的分割结果不能直接抹掉原来唯一正确的区域；有明显重叠但不同的分割也先分别核验 CAD，再按匹配质量去重，不在 CAD 检查前凭掩码重叠直接删掉。

提供 CAD 且文本区域不足时，最多尝试 4 个重叠图像局部裁剪，重新运行同一个检测模型，提高小目标的有效分辨率。不移动机器人。

此外可从 RGB-D 的深度连续性与颜色边界生成有限的无语义区域，使用已提供 CAD 的尺寸进行粗筛。这些只是待验证的搜索区域，不是“已经识别到目标”；必须通过原有 CAD 核验才能输出。恢复预算只预留一部分给此类区域，避免挤掉低分但可能正确的文本候选。未提供 CAD 的请求不能通过这一通道把任意点云区域叫作目标。

CAD 的表面距离、渲染深度、可见覆盖、自由空间冲突和歧义门槛均未放宽。新的搜索也不保证恢复全部漏检。
