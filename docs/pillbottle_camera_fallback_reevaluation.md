# 药瓶放置：定位不合理时尝试另一视角

## 单一改动

上一批 v20 的完整流程成功率为 40/50，官方评分为 41/50。seed 8 搬运后，头部相机的 CAD/深度匹配通过，但完整 CAD 范围距 TCP 约 12.4 cm；旧程序在返回该结果后才检查距离，随即停止，未继续尝试腕部相机。这个记录不证明药瓶掉落。

本次将原有“TCP 到当前深度验证的完整 CAD 范围不超过 3 cm”检查加入每个定位候选的接受过程。头部结果通过表面匹配但不符合距离要求时，拒绝该结果，直接转到活动臂的腕部相机；腕部仍需通过相同表面、桌面和距离门槛。两个视角均不可信仍停止，不释放。可信的头部结果仍直接使用，不强制增加腕部观测。

这是被动相机回退，不是主动移动相机，也不是双视角一致性融合；未恢复试抬，不增加仿真真值读取，不改变垫子目标估计、规划、执行到位门槛、松爪与撤离逻辑。旧 `legacy` 放置不启用新候选检查。

拒绝原因、距离和相机切换保存在每个阶段的 `precision_observation_attempts[*].candidate_validation`、`rejection_stage` 和 `next_action` 中。报告标记 `placement_candidate_proximity_before_camera_acceptance=true`。控制过程仍不能把闭爪和接近当作已抓稳证明。

全量 254 项回归测试通过。新增测试覆盖头部不合理后立即尝试腕部、两个视角均不合理时拒绝、可信头部结果不增加观测、旧分支保持原行为，以及放置流程实际传入候选检查。

## 评测口径

先单独复测 seed 8 检查相机回退是否实际触发，再固定与 v20 相同的已知模型 base1、连续 seeds 5–54 进行 50 轮评测。单种子测试不计入这 50 轮，不筛掉或替换失败种子。已有开发种子不是独立泛化测试。

```bash
cd /data1/xuhuixin/ula
GPU=7 bash scripts/run_move_pillbottle_pad_known_model.sh \
  --known-model 1 --known-approach annotated --known-contact-region all \
  --known-approach-search ranked --known-placement-policy visual \
  --episodes 50 --seed 5 \
  --output /data1/xuhuixin/ula/results/pillbottle_camera_fallback_50eps_20261031_seed5_v21
```

分别报告完整流程成功率、官方评分成功率和排除首轮后的成功轮平均时间；必要时比较共同成功种子的配对耗时。不得把视觉拒绝停止计作任务成功，不预填实验结果。

## 单种子功能复测

`results/pillbottle_camera_fallback_seed8_20261031_v21/report.json` 已结束，完整/官方均 0/1，保护文件一致。搬运后头部 `raw_box` 的表面配准通过，但 CAD 范围距 TCP 约 11.7 cm，新候选检查拒绝了它，并实际尝试 `right_camera` 的三种提示。腕部仍因分割候选不可信/可用点太少失败，所以未继续下降、未松爪。

这个结果验证的是相机回退逻辑真实触发，不是该失败样本已经修复；不能预期增加一个视角必然恢复任务。50 轮对照另存上文 v21 目录，包含 seed 8，不用该单种子结果替换批次中的一轮。

v21 的完整失败种子为 5、8、22、26、28、31、33、38、43、49：

- 5、22、26、33：运动到位检查失败，其中 33 已通过官方评分、撤离未完整通过。
- 28、31：初始视觉分割不可信，尚未进入 VLA 抓取。
- 8、38、49：搬运后头部 CAD 范围距 TCP 分别约 9.1、15.1、16.4 cm，候选检查拒绝后均实际尝试腕部三种提示，仍因重新分割不可信或可用点太少拒绝，未释放。
- 43：没有可行的搬运/下降规划组合。

结论：候选不合理后继续尝试腕部的逻辑已在真实评测中触发，但本批没有挽回这些失败，也没有提高整体成功率。已用上现有另一个视角不等于该视角能看清；后续仍需单独诊断腕部图像分割、可用深度和遮挡，而不是把闭爪当作抓稳证明或放宽 3 cm 门槛。本次未额外加入主动换视角、跨视角一致性融合、垫子定位修复或 VLA 重抓。
