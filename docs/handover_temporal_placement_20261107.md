# 交接后利用历史视觉与机器人运动处理遮挡

## 目标与范围

仅针对 handover_block 的最后放置阶段。左手和右手 pi0.5 检查点、各阶段动作预算、传统接近和中间搬运保持不变，不影响杯子等任务。不增加试抬，不用对象真值授权运动或释放。

新入口 `scripts/eval_pi05_handover_temporal.sh` 与原单帧观测入口分开。共享 adaptive_place 仅新增对显式时序质量字段的支持；旧观察器未提供该字段时仍按原规则执行。

## 方法

右手交接后，必须先得到一次通过原点云分组与拟合的、完整位置可确定的 RGB-D 观测。桌面初始位姿和闭爪指令不能独立作为此锚点。

之后用实际机器人 FK 的位移与转动预测方块位置，传播六维位置/旋转协方差；当前 RGB-D 的可见表面用于更新可观测方向。优化同时使用表面残差和历史协方差约束；某个方向缺少测量信息时，保留其历史预测和不确定性，而不把隐藏坐标重置成新测量。

跟踪阶段按预测表面一致性选择完整连通碎片，可同时使用被夹爪遮开的多个表面；即使单个侧面不能独立确定完整物体位姿，也可对已有时序状态提供部分约束。

当前表面 RMSE 仍需 <4 mm，6 mm 内点比例仍需 >85%。明显偏离历史预测、无足够当前表面或运动未到位均停止，不靠历史记忆盲目搬运。

## 隐藏底端释放规则

原来“当前帧完整位置可观测才松爪”改为允许使用有可靠锚点的时序估计，但增加显式置信范围要求：

- 当前仍须有足够且相容的可见目标表面；无观测不继续。
- 距最近完整观测不超过 30 个运动更新、累计平移不超过 0.5 m。
- 底端 XY 与 Z 的模型 2σ 尺度均不超过 5 mm。
- 估计 XY 偏差加模型不确定性不超过 8 mm；底端高度的模型区间完全落在平台上方 3–18 mm 的释放范围内。
- 保留最小倾斜修正与自由偏航，不强制固定完整朝向。

协方差噪声与上述预算是显式工程参数，不是校准后的实际 95% 覆盖保证，不等于真实物理抓稳证明。均匀长方块沿夹爪滑动、两端都被遮挡且侧面不变时，仅靠这些视觉与 FK 不能保证检测到滑动。模型可能低估误差，必须通过独立核验和完整任务测试评估，不能只看估计通过率。

## 已完成验证

- 完整单元测试 454 项通过，包含单面观测不抹除历史坐标、遮挡方向没有虚构测量信息、无初始完整视觉锚点拒绝、历史过期拒绝、当前可见突变拒绝、释放置信区间超界拒绝。
- `results/handover_temporal_replay_20261107_v1/report.json`：旧5场 RGB-D 与实际机器人运动序列全部可连续处理。独立核验底端最大误差约为 1.44、6.73、1.04、1.44、1.16 mm；其中一个样本的误差超过模型给出的尺度，说明不能把模型协方差当作实际误差保证。
- 离线回放中对象真值只在状态更新完成之后计算独立误差，不参与筛选、更新或释放。回放采用的是旧控制动作，不是新控制器的完整任务成功率。

## 完整任务验证

同旧实验，固定 seed 40026 起的5个有效随机场景，所有有效场景均计入分母，不按交接真值过滤执行。

```bash
cd /data1/xuhuixin/ula
GPU=7 HANDOVER_VISION_GPU=6 bash scripts/eval_pi05_handover_temporal.sh \
  --episodes 5 --seed 40026 \
  --output /data1/xuhuixin/ula/results/pi05_temporal_full_pilot5_seed40026_20261107_v1 \
  --detach
```

该实验为已分析种子的配对工程回归，不是未见场景泛化实验。最终以 report.json 的交接成功数、完整放置成功数和官方任务评分为准。
