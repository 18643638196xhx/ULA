# ULA 药瓶放置最小迁移验证

任务：RoboTwin `move_pillbottle_pad`。使用官方任务的随机物体、随机位置，不调用专家 `play_once()`，不筛选可成功的种子，不重新训练 WorldLA。

## 流程

先用头部相机的 RGB-D 识别药瓶和蓝色方垫，获得药瓶可见点云、桌面高度和垫子中心。根据药瓶在图像测得的世界坐标中的左右位置选择机械臂。当前默认从药瓶朝向机器人一侧接近：以可见水平范围中心为横向目标，以桌面到瓶顶的一半高度为瓶身目标，先停在可见前侧 6 cm 外，并张开夹爪。夹爪朝向从有限个俯仰、偏航候选中选择；只规划不运动，直到找到可行候选，执行后不继续试其他候选。`--approach-style top` 保留顶部接近版本用于比较，默认顶部间距为 4 cm。

WorldLA 接手完成局部抓取。所选机械臂的闭爪控制状态连续 3 个动作低于 0.05，并且机器人 TCP 已进入当前视觉药瓶点云的轴对齐空间范围（范围外允许 1.5 cm 距离）时，暂停 VLA。这里检查的是 TCP 与可见范围的距离，不要求 TCP 贴住某个表面点：夹住较粗瓶身时，夹爪中间的参考点可以位于瓶身内部，离表面仍有几厘米。只闭爪但离药瓶范围太远时继续由 VLA 对准。距离检查最多每 3 个 VLA 动作一次，使用头部相机，头部观测不可用才尝试腕部相机。这仍只是“可以尝试抬起”的候选，不代表已经抓稳，点云范围也不是真实完整物体体积。

传统控制先保存当前视觉基线，再分 3 段试抬 5 cm。通过同一相机前后点云配准，检查药瓶表面是否上移至少 3 cm，且运动方向、运动大小与手一致。头部相机结果不可信时，有限次改变分割提示，或改用匹配的腕部相机前后画面。看不清或不跟手就停止，不进入放置、不主动松爪。不使用仿真接触信息或相对滑移真值。

确认后，把抓前点云与当前头部相机点云配准，估计本轮药瓶运动。沿用杯子方案的近似支撑锚点：初始可见范围的水平中心、视觉桌面高度。假设药瓶初始直立并放在水平桌面上，将该锚点随配准运动更新，再计算对准视觉垫子中心所需的机械臂目标，补偿估计倾斜。先同时规划搬运和下降，两段都可行才执行；保留 3 mm 释放间隙，松爪后撤离。

这不是测到了被遮挡的瓶底，也不保证可见点云中心就是实际支撑中心。对称、遮挡、夹爪混入分割以及抓后滑动仍可能引入误差。放置阶段目前使用头部相机，最多重新分割一次；没有启用杯子完整的放置阶段腕部回退。

## 与已有任务隔离

- 新入口：`scripts/run_move_pillbottle_pad.py`、`scripts/run_move_pillbottle_pad.sh`。
- 新适配：`adapters/pillbottle.py`、`scripts/perceive_pillbottle_rgbd.py`。
- 只读复用既有 VLA、几何、ICP、轨迹与计时工具，不修改杯子、微波炉入口和共享算法源码。
- 既有工具的 `cup`、`coaster` 字段在本实验中分别代表药瓶、方垫；这只是接口别名，不会加载杯子的模型。
- 药瓶形状检查允许竖直长宽比不超过 4；这是显式的类别先验，不是从模型文件读出的尺寸。原杯子的阈值不变。

## 真值边界和评分

控制过程不读取药瓶/垫子的仿真位姿、CAD、标注接触点、功能点或物理接触。在线官方成功判定被禁用，VLA 的物体真值诊断也被临时禁用，退出后恢复。

仍依赖仿真产生的 RGB-D、相机标定，以及机器人模型、机器人状态和配置的桌面碰撞盒。不是“完全不使用仿真状态”，也不是完备的物体碰撞模型。

全部控制结束后才调用官方 `check_success()` 并读取物体位置评分。报告分别保存官方 `task_success` 与 `success`；后者要求控制流程完成且官方评分成功。`approach-only` 模式的 `success` 仅表示接近完成，不代表整个任务成功。

## 运行

显式指定一张有足够空闲显存的 GPU；不自动选择、不停止现有进程。显存分配预算不等于 GPU 硬隔离。

```bash
cd /data1/xuhuixin/ula
GPU=7 bash scripts/run_move_pillbottle_pad.sh \
  --episodes 1 --seed 0 \
  --output /data1/xuhuixin/ula/results/pillbottle_single_new
```

输出目录必须为空。每轮保存初始、接近、闭爪候选、抓取确认、结束画面，以及 RGB-D/点云、规划候选、阶段耗时、错误和评分。没有连续视频。

计时为主机墙钟时间，包含场景设置与保存文件。第一次还包含感知、VLA 加载与编译，不能作为稳定完成耗时；多轮报告同时提供剔除第一轮的统计。不同迭代版本及失败轮次必须分别保留，不应混合为最终成功率。

seed 4 的结果只能称为“视觉无法确认”，不能据此声称已经确认物理抓取失败，也不能称为抓稳成功。

所有批次的既有保护文件指纹均未变化；感知 worker 每批启动一次，实验结束后关闭。原始报告、阶段画面和失败日志均保留，没有修改原始 `/data2/xuhuixin/tra_pipe` 或外部 VLA/checkpoint 内容。

另外只读查到外部工作区的同一 checkpoint 药瓶纯 VLA 历史记录为 49/50，路径为 `/data2/xuhuixin/wam_vla_outputs/vlma_robotwin50_official/efficiency_10tasks_n50_gpu4_7/worldla/move_pillbottle_pad/attempt_00/run.json`。其使用 accepted seeds 和不同评测设置，不是本次 raw seeds 0–4 的配对对照，不能直接与本次 0/5 比较，更不能据此把失败归结为模型本身不具备药瓶任务能力。

结论：最小迁移验证尚未成功。主要未解决的是接近的实际到位以及 VLA 对中途接管姿态的适应；还需排查抓后视觉观测。下一步应先对齐 VLA 的接管状态、检查轨迹实际执行，再开展配对小样本验证，不宜直接扩大到 50 次或继续放宽抓稳判定。
