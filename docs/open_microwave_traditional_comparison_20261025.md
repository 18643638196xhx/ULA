# 微波炉：去掉 VLA 的纯传统控制对照

## 测什么

任务仍是 `open_microwave`，不是重新测试杯子放置。新增 `--mode traditional`，默认 `hybrid` 不变，杯子放置代码不变。

本对照采用最初杯子传统方案的基本思路：视觉估计目标，传统规划到位，然后执行闭爪；不能把杯子的接触点编号或抬升、放置动作直接复制到微波炉。这里沿用微波炉现有视觉几何目标，不引入物体 CAD、接触点标注或仿真物体位姿。

| 环节 | 混合方案 | 本次纯传统方案 |
| --- | --- | --- |
| 门面和把手识别 | 相同的 RGB-D / DINO / SAM / 深度几何 | 相同 |
| 接近 | CuRobo 分段规划，TCP 在把手前约 2.5 cm | 相同 |
| 局部闭爪 | WorldLA 根据图像与状态生成动作，达到候选条件后中断 | 不使用 WorldLA，在已到位的几何目标处执行一次传统闭爪轨迹 |
| 闭爪候选检查 | TCP 距视觉把手不超过 3 cm，连续 3 个 VLA 动作满足闭爪命令条件 | 闭爪前后 TCP 距视觉把手不超过 3 cm，闭爪轨迹执行成功且命令低于同一阈值 |
| 抓取是否有效 | 重新观察，然后由传统控制首次试拉并检查视觉随动 | 相同 |
| 连续开门 | 传统控制约 3° 小步规划，逐步观察 | 相同 |
| 控制目标和评分 | 70° 目标、既定收敛范围和随动检查，再要求原始评分通过 | 相同 |

两种闭爪方式均不把闭爪控制值当作抓稳证明。纯传统模式没有 VLA 的三个离散动作，所以不伪造三个 VLA 动作计数；验证抓取的首次试拉条件保持不变。这里“纯传统”指没有 VLA 动作策略，视觉模块仍包含学习模型，不是完全不使用神经网络。

没有调用 RoboTwin 原生 `play_once()`。原生脚本直接使用物体接触点和真实门关节信息，输入条件不同，不作为本次无物体真值视觉方案的公平消融。

## 实验设置

50 轮，seed 0–49，与当前混合方案的 `microwave_repair_50eps_seed0_20261025_v2` 对齐。每轮先到约 8 cm 接近点（未执行时允许有限候选），再以每段不超过 2 cm 到最终 2.5 cm；初始夹爪控制值 0.45，传统闭爪目标 0。开门目标 70°，每步最多 3°，最多 40 步，不降低随动门槛、不删除失败 seed。

模型与视觉分工：纯传统批次不构造、加载、调用 WorldLA，`vla_used=False`，VLA 动作计数应为 0。仍保留常驻视觉进程。GPU 7 运行仿真/规划，GPU 0 运行视觉，不影响其他进程的启动和结束。PyTorch 分配器各为整卡 10%；启动器中的 JAX 45% 只是环境配置，本模式不加载 VLA 的 JAX 模型，不表示实际分配了这部分显存。共享 GPU 不是硬隔离。

在线控制不读物体姿态、门关节、接触或物体身份标签；使用仿真 RGB-D、机器人状态、相机标定与几何先验。控制完全结束后才读取原始成功评分、门关节和限位。

纯传统专项 smoke：seed 0、1、2 均完整成功，`vla_steps=0`，视觉进程正常关闭，放置文件校验一致。该 3 轮只是入口验证，不纳入正式 50 轮成功率。CPU 回归共 171 项通过，新增覆盖远处不闭爪、闭爪失败不试拉、传统模式不构造 VLA、原有混合路径和真值隔离。

正式命令（输出目录需为空）：

```bash
cd /data1/xuhuixin/ula
GPU=7 MICROWAVE_VISION_GPU=0 MAX_JOBS=2 \
  OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
  bash scripts/run_open_microwave.sh \
  --mode traditional --episodes 50 --seed 0 \
  --approach-clearance 0.025 --approach-gripper 0.45 \
  --max-vla-steps 100 --target-angle-deg 70 \
  --output /data1/xuhuixin/ula/results/microwave_traditional_50eps_seed0_new
```

`--max-vla-steps` 在本模式中只是兼容入口的动作预算配置，不会启用 VLA。

## 正式结果（50/50 已结束）

| 指标 | 无 VLA，纯传统 | 当前混合方案 |
| --- | --- | --- |
| 完整流程成功 | 36/50（72%） | 39/50（78%） |
| RoboTwin 原始评分成功 | 45/50（90%） | 44/50（88%） |
| 排除第一轮后，完整成功轮平均总耗时 | 8.002 s（35 轮） | 8.219 s（38 轮） |

完整流程要求通过现有 70° 目标的收敛范围及逐步视觉随动检查，并通过原始评分。原始评分的门角要求低于该控制目标，因此可能门已达到原始任务标准、但新控制器因观测或随动检查停止。纯传统有 9 轮属于这种情况，混合方案有 5 轮；不能把原始评分成功率和完整流程成功率混用。

成功率包含全部 50 轮。总耗时从环境设置到最终评价和画面保存；第一轮仅从耗时平均中剔除，不从成功率中删除。含失败的全部尝试排除第一轮后平均为 8.169 秒。两列成功耗时的样本集合不同；进一步只取双方都成功、且不是第一轮的同一组 31 个 seed，纯传统平均 7.990 秒、混合方案平均 8.205 秒。这仍是共用 GPU 上各一个批次的观测，不能视为多次重复实验的确定性速度差。

纯传统成功轮（排除第一轮）的平均阶段耗时：

| 阶段 | 平均耗时 |
| --- | --- |
| 环境设置 | 0.215 s |
| 视觉识别与传统接近 | 1.236 s |
| 传统闭爪 | 0.117 s |
| 闭爪后视觉基准 | 0.064 s |
| 传统试拉与连续开门 | 6.061 s |
| 画面保存等 | 0.308 s |

实际记录核对：50 轮的 `vla_used` 全部为 False，`vla_steps` 全部为 0，计时中没有 `vla_load` 或 `vla_close` 阶段。六个冻结源码校验均通过，四个受保护放置文件与启动前及原始校验一致。视觉进程仅启动一次，结束后已关闭；GPU 0、7 显存回到约 18627、18626 MiB 的原始任务占用，没有停止其他进程。

## 失败与对照解读

纯传统失败 14 轮：

| 阶段 | seed | 已确认的现象 |
| --- | --- | --- |
| 初始识别 | 46、47 | 无可信门/把手组合，未执行接近 |
| 闭爪后基准 | 7、17、31 | 头部和腕部观测均被拒绝，未试拉 |
| 开门中视觉位置跳变 | 5、20、23、34、41 | 最后可信角约 62–68° 后，新观测跳到约 3–5°、把手跳变约 13–15 cm，被一致性检查拒绝；不能据此认定门真的关回去了 |
| 开门中观测失败 | 14、30 | 最后可信角约 61.80°、68.81° 后观测被拒绝 |
| 收尾随动不足 | 28、37 | 单步把手位移约 1.63、1.54 mm，未通过原有 2 mm 门槛；seed 37 单步角度进展也不足 |

最后三类共 9 轮都通过了原始任务评分，但仍不算完整流程成功。

混合成功、纯传统失败：5、14、20、23、28、34、41，共 7 轮。
纯传统成功、混合失败：1、18、38、44，共 4 轮。
两边均完整成功 32 轮，均失败 7 轮。因此混合方案净多成功 3 轮，即 6 个百分点；不是每个 seed 都优于纯传统。

本次可得的结论是：当前几何接近后直接传统闭爪已经可以完成不少任务，混合方案在这一批的完整流程成功率稍高，但原始评分没有更高。尤其纯传统的 9 个开门中止轮均已达到原始评分条件，说明当前瓶颈还包括开门后的视觉跟踪与收尾判定，不能把全部成功率差异解释为 VLA 抓取能力的收益。单批次 50 轮不足以证明稳定的优劣，也不能推广到未知设备、不同把手或其他任务。
