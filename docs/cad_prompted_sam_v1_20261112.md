# 独立实验：在 SAM 重分割时使用 CAD

这是新增目录 `adapters/cad_prompted_sam_v1` 和独立入口，不修改 `adapters/unified_vision`、现有任务入口、原配置或历史结果。正在运行的四任务200场身份/空域实验保持原样。

## 流程

1. 使用原文字检测、SAM 与 RGB-D 恢复生成初始候选。普通恢复预算仍为12个候选。
2. 对其中语义分最高的最多3个候选执行原 CAD 配准。只有通过原核验、能输出模型深度投影的粗位姿才用于提示，不使用仿真位姿。
3. 在 CAD 投影内、实测深度与模型深度相差不超过原8mm门槛的区域，选最多5个分散正点。遮挡、缺深度的像素不作为正点。
4. 在所有保留粗位姿投影之外的窄环中选最多5个负点，减少某一候选把另一候选覆盖区域当作负样本。CAD投影包围框只作为搜索提示，不当作正确分割掩码。
5. 全图重新调用 SAM，最多保留每个粗位姿2个新掩码。原12个候选全部保留，不为新增结果丢弃原候选；独立引擎预留18个槽位。基线分支也使用相同普通恢复预算和引擎槽位，只不添加 CAD 提示分割。
6. 新掩码没有预先赋予 CAD 通过状态，仍要重新检查图像语义、点云和 CAD；保存提示点、粗位姿、SAM分数与最终核验结果。

代码复用原模型权重，不修改权重，不生成隐藏深度点。粗位姿来自初步分割，而非“把CAD直接交给SAM”。此版本仅利用每个粗候选的最佳已核验位姿；不重新展开其全部旋转假设，也未实现多视角、无CAD恢复或精确部件拓扑。

## 风险与限制

初始候选没有任何可接受CAD配准时，本版不会凭空生成提示。错误粗配准也可能产生错误提示，因此只保留新增候选而不覆盖原候选；保留并不保证选择结果不会退化。语义分排序的3个种子预算可能漏掉低语义分但正确的粗候选。外部负点仍依赖粗位姿，应通过实际对照验证，不宣称保证排除邻近物体。

当前独立基线使用严格语义支持、颜色核验和旧可见表面补全，不启用新增身份成本或局部空域规则，也不启用断点补全，避免混合实验。两组使用相同保存图像、查询和推理随机种子；GPU数值不保证逐位一致。
