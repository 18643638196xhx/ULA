# 已知药瓶：快速接近候选搜索

## 改动范围

仅改变已知模型药瓶分支的接近候选搜索和该分支计时，不改 Cup、Microwave、无模型药瓶、官方 RoboTwin、外部 VLA 或传统放置算法。不新增试抬，不降低视觉配准/关节限位/实际到位门槛。

旧版 `--known-approach-search legacy` 保留。新版 `ranked` 为当前已知模型入口的默认选项；用于 `annotated` 接近，`diagonal` 消融不使用此搜索器。复现原 50 次基线时必须明确指定 `legacy`，不能把新默认值的结果当成旧算法复测。

## 为什么原版慢

原版对 base1 的 16 个标注接触点分别生成 10 个旋转姿态，并为每组调用完整批量轨迹规划，再按姿态偏好挑出接近目标。选中后还会重新规划一次执行轨迹。31 次成功样本中，平均传统接近阶段为 13.221 s，其中约 11.756 s 未被旧组件计时单独覆盖；不能在未补计时前宣称全部是批量规划耗时。

## 新流程

先将相同的 CAD 接触点通过当前视觉位姿转换到世界坐标，沿用官方坐标定义生成同样的 160 个接近姿态。这一步只做几何计算，不调用 `get_grasp_pose` 或 `choose_grasp_pose`，避免其内部直接开始轨迹规划。

先优先接近原任务偏好的上方姿态，其次为机械臂偏好的侧向姿态，再考虑两者的加权距离；同分时优先末端平移较短的候选。方向偏好和 0.15 姿态距离阈值沿用原官方规则，但排序发生在所有候选上，因此**不保证最终目标与旧版逐接触点挑选的目标相同**。即使可达，新的接近朝向也可能影响 VLA 抓取，必须验证任务成功率，不能只比较速度。

按排序逐个规划前 8 个候选，找到轨迹可行且未超机器人关节限位的候选就停止；这 8 个都失败，再对剩余候选按顺序分批规划。原批规划器预热批大小为 10，因此不足 10 个时只在批末复制最后一个输入补齐，补齐项不会成为新候选或执行目标。最坏情况下仍覆盖原接触区域内全部候选，不把候选池永久缩减成 8 个。所有搜索均发生在执行前，不能通过执行失败的候选来“试路”。

直接使用选中规划返回的轨迹执行，不为相同目标重新规划。原有降速、实测关节与末端到位、接近状态稳定交接、视觉粗接管、精定位、传统搬运/下降/松爪/撤离流程保持不变。搜索都失败则停止；不会因为放宽门槛而允许移动。

## 计时与审计

交接结果 `geometry_approach` 保存几何生成耗时、选中候选/名次、单目标与批量规划次数/耗时、是否扩大搜索和是否复用轨迹。

另外在已知模型运行器的局部计时上下文中覆盖 `choose_grasp_pose` 与 `left/right_plan_multi_path`。旧算法的批量规划不再混入未细分开销。计时补丁退出时还原，不改共享计时源码；阶段总耗时不受组件分类变化影响。组件 `components_s` 为互斥项，`inclusive_s` 为嵌套诊断，不能相加。

## 命令

```bash
cd /data1/xuhuixin/ula
GPU=7 bash scripts/run_move_pillbottle_pad_known_model.sh \
  --known-model 1 --known-approach annotated --known-contact-region all \
  --known-approach-search ranked --episodes 5 --seed 0 \
  --output /data1/xuhuixin/ula/results/pillbottle_fast_pregrasp_new
```

原算法同条件对照：将 `ranked` 换成 `legacy`，使用另一个空输出目录。保留旧实验报告，不能覆盖或改写旧 50 轮结果。

## 开发种子五轮复测（v15）

结果目录 `results/pillbottle_known_ranked_approach_5eps_20261031_v15`。固定 base1、seeds 0–4、不试抬，完整/官方成功均为 **4/5**，成功 seeds 0、1、3、4，与原 v12 相同。seed 2 仍停在抓后精定位，没有因此继续搬运或松爪。5 轮均没有调用扩大批量搜索，分别做了 4、1、1、1、3 次单目标规划；几何候选生成约 0.018 s，候选选择规划约 0.09–0.44 s。

为避免不同成功种子和冷启动造成误导，下面只比较两版均成功且剔除首轮的相同 seeds **1、3、4**：

| 项目 | 原版 v12 | 新版 v15 |
| --- | --- | --- |
| 传统接近 | 11.721 s | 1.537 s |
| VLA 抓取 | 3.156 s | 3.408 s |
| 传统搬运放置 | 5.844 s | 6.252 s |
| 整轮墙钟时间 | 21.377 s | 11.827 s |

接近计算开销明显减少，但这 3 个共同成功样本不足以证明平均性能或成功率稳定；新的朝向选择也可能改变 VLA 和传统放置耗时，不能保证总时间减少量恰好等于候选搜索减少量。不能把本表与旧 50 次成功均值 19.076 s 直接作同样本比较。

240 项全量回归通过，杯子/微波炉/无模型药瓶/官方代码保护指纹一致，v15 工作进程已关闭。单元测试覆盖几何生成不规划、首次成功提前终止、关节限位拒绝、全候选回退与批末补齐、失败不移动、执行轨迹复用及计时补丁异常恢复。

## 配对 50 轮复测（v16）

为与旧版 `pillbottle_known_traditional_finish_50eps_20261031_seed5` 对照，新版保持相同 base1、连续 seeds **5–54** 和全部控制参数，仅改接近搜索，运行期间冻结源码，不筛选/替换失败种子。

```bash
cd /data1/xuhuixin/ula
GPU=7 bash scripts/run_move_pillbottle_pad_known_model.sh \
  --known-model 1 --known-approach annotated --known-contact-region all \
  --known-approach-search ranked --episodes 50 --seed 5 \
  --output /data1/xuhuixin/ula/results/pillbottle_known_ranked_approach_50eps_20261031_seed5_v16 \
  > /data1/xuhuixin/ula/results/pillbottle_known_ranked_approach_50eps_20261031_seed5_v16.log 2>&1
```

本文件此处不预填 50 轮成功率；以该批 `report.json` 实际完成数量、工作进程关闭和保护指纹结果为准。最终统计完整成功和官方评分两种口径；对耗时既列各自成功样本，也应单列两版共同成功、剔除首轮的配对样本，避免成功集合改变造成假加速。
