# 50 任务已知 CAD 视觉定位专项

日期：2026-11-10。本批是用户确认的 **50 种任务 × 每种 50 个有效 randomized 场景，共 2500 场**。只采集初始头部 RGB-D，验证物体识别与位置；不运行 VLA，不执行抓取、搬运、放置或开门，也不统计完整任务成功率。

## 已知模型的含义

每场明确提供本轮目标对应的具体模型，而不是让视觉模块从全部型号中猜测是哪一个。目标的型号、尺寸、已知外观由场景生成端作为实验输入提供，属于已知实例先验；这不是无模型实验，也不是“只告诉类别”的陌生实例识别实验。

输入不含目标世界位置、朝向、像素标签、接触点或功能点。视觉 worker 是独立进程，只接收 RGB-D、相机标定、文字描述和静态 CAD。它仍须在杂物中找到候选，逐候选配准并通过几何、轮廓和深度一致性核验。

普通物体使用对应视觉网格与资产尺度；程序生成的方块、垫子使用声明的尺寸和颜色构造模型。关节物体从 URDF 的静态结构和声明的初始关节配置组装模型，不读取运行中的关节状态。笔记本采用任务定义的初始关节范围 20%；之后若物体因物理作用偏离初始形状，当前刚体配准不保证适用。

## 测哪些目标

任务清单、顺序已与本地官方 `all_tasks.yml` 的 50 种任务逐项核对一致。具体目标由 [vision50_catalog.py](/data1/xuhuixin/ula/diagnostics/vision50_catalog.py) 固定，例如杯子＋杯垫、药瓶＋垫子、面包＋篮子、红绿蓝方块等。没有用物体真值坐标排序后告诉检测器目标在哪里。

本轮是**初始物体级定位**：微波炉、笔记本、锅、开关、柜子评分的是初始状态下的整体物体，不是把手、按钮、门缝或隐藏关节。因此不能用这里的主体通过率代替操作部件定位能力，也不代表完整任务已能执行。

同模型、同外观描述的多实例在评分时允许交换身份，但使用一对一匹配：对两只相同碗返回同一只两次，最多算对一只，不会虚增为两个通过。

## 场景与评分

使用 ULA 本地 RoboTwin 实现、`demo_randomized`、Aloha AgileX、初始头部相机。只读取该相机，不主动移动机械臂观察。原场景稳定性检查保留，从 seed 0 开始按连续种子尝试；初始化不稳定单独记录并顺延，直到每个任务有 50 个成功初始化场景，或触及明确的重试预算。没有用传统专家能否完成任务筛选场景。

各场预测文件落盘并哈希锁定后，才读取同一画面的独立渲染身份标签评分，标签不回传 worker，也不触发重测。当前任务内完成一次预测后直接评分，不宣称“全部 2500 场预测完成前从未读取任何评分标签”；代码和参数预先冻结，并逐场检查没有修改。

单目标定位通过要求：当前输出满足查询，选中区域至少 80% 为目标且重叠至少 20 像素，可见表面范围中心误差不超过 2 cm。这个位置不是隐藏物体中心、模型原点或支撑点；本轮也没有核验完整六自由度位姿。

每场所有预定目标都通过，才记作该场联合定位通过。报告同时保留单目标计数、未输出、区域错误、位置未核验和目标不可见数量。目标不可见与定位拒绝分别披露；不把只输出坐标算成定位正确。基础设施异常单独报告；若有场景未完成评分，不生成误导性的完整定位率。

## 运行与隔离

正式目录为 [unified_vision50_known_cad_randomized_50per_task_20261110_v1](/data1/xuhuixin/ula/results/unified_vision50_known_cad_randomized_50per_task_20261110_v1)。使用启动时空闲的 GPU 0、1、2、3，每张卡同时只运行一个任务，任务完成后自动接下一个。

每个任务的 50 场复用一个视觉 worker，DINO、SAM、FoundationPose 网络不按场景反复加载。不同任务使用独立进程，限制模型缓存生命周期；模型缓存上限改为 256，以容纳随机型号和程序生成几何体，但没有修改配准、覆盖率、深度、歧义等接受门槛。

初始采图不需要机械臂路径规划，因此仅在这个评测进程里禁止 CuRobo/MPlib 规划器的导入和构造，保留原机器人初始化、原有 200 点夹爪线性插值、物理沉降和稳定性检查。任务初始化后另有动作禁止保护。没有修改 RoboTwin 任务文件、已有控制器、模型权重或历史结果。

预检查 v1 在导入不需要的 CuRobo 时触发环境编译错误，未产生定位结果；独立进程隔离修复后，v2 的杯子、交接方块、微波炉、笔记本 4 场均完成整条评分链路。预检查中的定位拒绝没有用于放宽算法门槛。正式代码全项目 **622 项测试通过**，包括 12 项新增评测工具测试。参见 [测试日志](/data1/xuhuixin/ula/results/unified_vision50_all_tests_20261110_v2.log)。

## 查看进度

[总进度 report.json](/data1/xuhuixin/ula/results/unified_vision50_known_cad_randomized_50per_task_20261110_v1/report.json) 每约 2 秒更新。`evaluated_scenes` 表示已评分场数，`finished_tasks` 表示已完成 50 场的任务数，`failed_tasks` / `process_failures` 单独记录运行异常。`active_processes` 给出当前任务、GPU 和进程号。

```bash
cd /data1/xuhuixin/ula
external/pi05/.venv/bin/python -c '
import json
from pathlib import Path
p=Path("results/unified_vision50_known_cad_randomized_50per_task_20261110_v1/report.json")
d=json.loads(p.read_text())
print("状态:", d["status"])
print("已评分:", d["evaluated_scenes"], "/", d["requested_valid_scenes"])
print("已完成任务:", d["finished_tasks"], "/", d["requested_tasks"])
print("异常任务:", d["failed_tasks"])
print("正在运行:", d["active_processes"])
'
```

逐任务报告在 `tasks/<task>/report.json`，日志在 `logs/<task>.log`。逐场目录 `tasks/<task>/case_*` 保存原图 `initial_head.png`、RGB-D、公开查询、模型来源与尺度、预测哈希、独立评分标签及叠加图 `audit.png`。实际候选掩码、点云和逐候选 CAD 核验保存在该任务的 `vision_worker/` 下。

正式评测尚未结束时，不把预检查的单场结果或部分进度称为 50 任务最终通过率。
