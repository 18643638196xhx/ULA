# RoboTwin 50 个任务的示范规则（修订版）

> **核对依据**：官方仓库 `RoboTwin-Platform/RoboTwin`，commit `ea8b211`（2026-09-24），`envs/` 下 50 个任务实现（`setup_demo / play_once / check_success`）。本版在初版基础上逐任务对照官方代码修订。
> **修订日期**：2026-11-12

## 修订说明

- 初版多数条目只写"做了什么"，本版为每条补充 **官方 `check_success` 成功判据**（`_base_task.py` 的 `place_actor` 默认 `dis=0.02, is_open=True`，即"放置"收尾必然开爪）。
- 修正初版的事实性错误与过度解读：`shake_bottle_horizontally`、`blocks_ranking_size`、`press_stapler`、`put_bottles_dustbin`、`rotate_qrcode`、`stamp_seal`、`beat_block_hammer`、`dump_bin_bigbin` 等。
- 初版把"单条示范的实测值"写成固定规则的地方，本版标注为"该条示范实测，非固定规则"。
- 官方任务是**脚本化 demonstration**；这里描述的是"示范里实际发生什么 + 成功条件"，不是要求运行时逐字复刻。"传统控制 / VLA"是 ULA 的分解用语，官方代码并不含 VLA。

## 逐任务规则

1. **adjust_bottle**
   - 动作：瓶子横躺桌面随机一侧（x∈[-0.12,-0.08] 或 [0.08,0.12]，model 13/16 随机）；按侧选臂抓瓶身中部 → 抬 0.1 m → 把功能点 0 放到同侧 [±0.25,-0.12,0.95]，保持闭爪。
   - 成功：`fp0.x < -0.15`（左）/ `> 0.15`（右）且 `fp0.z > 0.9`。**不校验朝向**。

2. **beat_block_hammer**
   - 动作：按方块侧选臂抓锤 → 抬 0.07 m → 把锤功能点 0 下探到方块上表面（`pre_dis=0.06, dis=0`），保持闭爪。
   - 成功：锤 fp0 与方块 fp1 的 xy 差 < 2 cm，且 `check_actors_contact(hammer, block)` 为真。
   - 注意：**没有"往复敲击"**，只有一次下探；结束时也不撤离。

3. **blocks_ranking_rgb**
   - 动作：严格按红→绿→蓝顺序；每块按当前 x 选臂，目标为从左到右一行（红 x∈[-0.09,-0.08]、绿 x∈[-0.01,0.01]、蓝 x∈[0.08,0.09]，同一 y∈[-0.2,-0.1]）。
   - 成功：三块相对间距 `|Δx|<0.13`、`|Δy|<0.03`、x 单调递增、双爪张开。
   - 注意："两臂交替"不是代码保证——臂由每块随机 x 决定，可能同侧。

4. **blocks_ranking_size**
   - 动作：实际搬运顺序是 **小→中→大**（block3→block2→block1）；最终摆放从左到右才是 **大/中/小**（大 x∈[-0.1,-0.09]、中 x∈[0.01,0.02]、小 x∈[0.08,0.09]，同 y∈[-0.2,-0.1]）。
   - 成功：`|Δx|<0.13`、`|Δy|<0.03`、x 单调递增、双爪张开。
   - 注意：初版"按大→中→小顺序搬运"写反；目标条带在 y≈-0.15，不是桌面几何中心 y=0。

5. **click_alarmclock**
   - 动作：移到按钮上方固定朝下 → 闭爪到 0 → 沿 -z 下压 6.5 cm → 回升 6.5 cm。闹钟 `is_static=True`，只按压不抓取。
   - 成功：该侧夹爪闭合，且夹爪与闹钟 contact point 0 的 xy 3 cm、z 3 cm 内有接触。

6. **click_bell**
   - 动作：接近铃顶上方并闭爪（`pre=grasp=0.1`，无二次下探）→ 下压 4.5 cm → 回升 4.5 cm。
   - 成功：该侧夹爪闭合，且与铃 contact point 0 的 xy 2.5 cm、z 3 cm 内有接触。

7. **dump_bin_bigbin**
   - 动作：大箱固定在左侧地面 [-0.45,0,0]，小箱随机 x∈[-0.2,0.2]。按小箱侧选抓取臂，倒出恒用左臂。小箱在右侧时：右臂抓 → 抬 0.08 → 放到中间位 [0,-0.1,0.741] 并松手 → 左臂重抓；左臂把箱举到 [-0.45,-0.05,1.05] 做 3 次倾倒（第二次带 0~2 cm 抖动）→ `delay(6)` 保持闭爪结束。
   - 成功：小箱 z ≥ 1.0，且 5 个球 z 均在 [0.13,0.25]（**不校验 xy**，即不校验球是否真落进大箱）。
   - 注意：初版漏了右侧"右臂→左臂"换臂分支；"保持到内容物落入后恢复/撤离"不成立（只有 `delay(6)`）；"四分之一圈"取决于抓取时腕姿，无法静态核实。

8. **grab_roller**
   - 动作：左右臂对滚筒两端 contact point 0/1 近同步抓取 → 同时抬升到 z=0.85，保持姿态。
   - 成功：双爪均闭合且滚筒 z > 0.8。

9. **handover_block**
   - 动作：方块生成在左侧（x∈[-0.25,-0.05]），恒左臂先抓 → 抬 0.1 → 放到中间位 [0,0,0.9] 保持闭爪；右臂抓另一侧 → 左臂开爪 → 左臂抬起回原位，同时右臂把方块放到蓝色目标板 fp1 后松开。
   - 成功：方块 fp0 与目标 fp1 的 xy 差 < 3 cm、z 差 < 1 cm，且**右爪张开**。
   - 交接：满足"左闭合 → 右闭合 → 共同持有一段 → 左才开"。

10. **handover_mic**
    - 动作：按麦克风侧选第一只手抓取 → 抬 0.12 并转腕到指定方向 → 搬到共同可达区 [0,-0.05,0.98] 保持闭爪；接收手闭爪后交出手开爪；交出手抬 0.07、接收手横移 ±0.05 继续持握。
    - 成功：接收手闭合 + 交出手张开 + 麦克风 fp0 z > 0.92 + 麦克风落在接收手一侧（x 符号匹配）。
    - 交接：满足"原手闭合 → 接收手闭合 → 共同持有 → 原手才开"。

11. **hanging_mug**
    - 动作：左臂先抓杯 → 放到桌面中部 [0,-0.15,0.75] 后松手 → 左臂抬 0.1 回原位，同时右臂抓杯 → 按杯把/支架功能点对齐（fp0, `align`, `dis=-0.05`）把杯把套到支架上 → 沿夹爪轴回撤 0.1。
    - 成功：杯 fp0 的 xy 距"杯架位姿—杯架 fp0 中点" < 2 cm、杯 fp0 z > 0.86、右爪张开。

12. **lift_pot**
    - 动作：双臂先半闭爪到 0.5 → 分别抓锅两侧把手（cp0/cp1，`pre=0.035`）→ 同步竖直抬升约 10 cm（到 z≈0.88）。
    - 成功：锅内位姿 z > 0.82、左右 TCP 到各自接触点 < 3 cm、锅身 z 轴与竖直方向点积 > 0.8。
    - 注意："保持水平"是成功判据（约 ±37° 宽容度），不是控制量。

13. **move_can_pot**
    - 动作：抓罐 → 抬 10 cm 并沿 -y 移 10 cm → 放到锅侧固定点（锅位姿 x±0.18、与锅同 y、z=桌面高度、姿态对齐锅）。
    - 成功：罐与锅 `|Δx|<0.2`（且符号在臂侧）、`|Δy|<0.035`、罐 roll≈90°±15°、`|pitch|<15°`、罐落回桌面（z ≤ 锅初始 z + 1 mm）、双爪张开。
    - 注意：初版"锅旁空闲区域/必要时调整朝向"不准确——是固定 0.18 m、同 y（±3.5 cm），且朝向对齐是**无条件**的。

14. **move_pillbottle_pad**
    - 动作：抓药瓶 → 抬 5 cm → 把药瓶功能点 0 对准垫子顶面中心（fp1）下降释放。
    - 成功：药瓶 xy 距垫中心 < 3 cm、`|z-(0.741+bias)| < 5 mm`、双爪张开；**不查朝向**。

15. **move_playingcard_away**
    - 动作：按牌侧选臂抓牌 → 沿世界 x 水平拖出 0.3 m（不抬起）→ 开爪。
    - 成功：`|x| > 0.23` 且双爪张开；不校验 y、z。

16. **move_stapler_pad**
    - 动作：抓订书机 → 沿夹爪接近轴回撤 0.1 m → 搬到颜色垫并对齐到固定姿态 [0.707,0,0,0.707] 后释放。
    - 成功：位置每轴差 < 2/2/1 cm、姿态四元数接近等分量族（`abs(q).max()-min() < 0.02`）、双爪张开。

17. **open_laptop**
    - 动作：笔记本 lid 初始开度 20%；先抓屏幕边缘 cp0 → 循环（≤15 次）重抓屏幕边缘当前点并拉动，直到开度达到行程 50%（≈ -0.925 rad，相对初始再抬约 32°），TCP 到 cp1 < 0.1。全程不主动松爪。
    - 成功：`qpos ≥ limit0 + 0.5*行程` 且 TCP 到 cp1 < 0.1。
    - 注意：`play_once` 用 `target=0.5`，而 `check_success()` 默认 0.4，两者不同。

18. **open_microwave**
    - 动作：抓门把手 cp0 → 循环（≤50 次）把 TCP 移到门上当前接触点 cp4 并拉动，开度增量 ≤ 0.001 或达到行程 70%（≈ 1.10 rad / 63°）即停。失败时备选：开爪 → 下移/后移 → 重抓 cp1（第二次 `pre=0.02`）→ 改由 cp2 拉动（≤30 次）。
    - 成功：门开度 ≥ 行程 70%（≈ 63°）。
    - 注意：**没有门轴约束**；"成弧"是反复移到标注接触点的物理结果。初版漏了整套备选策略；`play_once` 用 `target=0.7`、判分默认 0.6。

19. **pick_diverse_bottles**
    - 动作：两瓶分别生成在左右半区（臂与半区**硬绑定**，不是识别后分配）→ 双臂近同步抓取 → 同时抬 0.1 m → 再把两瓶搬到固定悬空保持位 [±0.06,-0.105,1.0]，全程保持闭爪。
    - 成功：两瓶 fp0 的 xy 距各自目标 < 0.1、z > 0.89。
    - 注意：初版只写"抬升"，漏了第二次搬运——**只抬升过不了判分**。

20. **pick_dual_bottles**
    - 动作：两瓶 model 固定 13/16 → 双臂近同步抓取 → 抬 0.1 m → 搬到固定悬空保持位 [±0.06,-0.105,1.0]，保持闭爪。
    - 成功：两瓶 fp0 的 xy 距目标 < 0.1、z > 0.89。
    - 注意：同为初版漏动作；`check_success` 里 `if ...: self.actor_pose=False` 是无效赋值，不影响判定。

21. **place_a2b_left**
    - 动作：按 A 的 x 侧选臂抓 A → 抬 0.1 → 搬到 B 左侧 0.13 m 处下降释放。
    - 成功：A-B 的 xy 距离 ∈ (0.08, 0.2)、A.x < B.x、`|Δy|<0.05`、双爪张开。

22. **place_a2b_right**
    - 动作：同上镜像，搬到 B 右侧 0.13 m 处。
    - 成功：A.x > B.x，其余同 21。

23. **place_bread_basket**
    - 动作：面包 1-2 个；分居两侧时双臂同时抓，然后左臂先放（`pre=0.13`）、回原点，右臂再放（`pre=0.13, dis=0.05`）——**抓取并行、放置串行**；同侧/单面包时单臂逐个。
    - 成功：每个面包 `|Δxy|<0.05`、z > 0.73 + bias、双爪张开。
    - 注意：初版"双臂可以并行"易被读成全程并行。

24. **place_bread_skillet**
    - 动作：一手抓锅、另一手同时抓面包 → 双手各抬 0.1 → **持锅手把锅搬到固定位姿 [±0.1,-0.05,z-0.05] 并翻腕**（关键中间步）→ 持面包手把面包放到锅内（锅 fp0，`pre=0.05, dis=0.05`）。
    - 成功：面包相对锅的 `|Δxy|<0.035`、锅/面包 z > 0.76 + bias；不检查爪状态。
    - 注意：初版漏了"搬锅+翻腕"这一步，它直接决定面包落点。

25. **place_burger_fries**
    - 动作：左臂抓汉堡、右臂抓薯条（同时抓）→ 各抬 0.1 → 左臂放汉堡到托盘 fp0，抬 0.08；左臂回原点同时右臂放薯条到 fp1，抬 0.08。
    - 成功：两种食物到托盘两个功能点的 xy 距离均 < 0.08、双爪张开。

26. **place_can_basket**
    - 动作：先抓罐 → 放入篮子（选较近功能点，`dis=0.02`，保持闭爪）→ 显式开爪释放、抬 0.12；随后另一只手抓篮子把手（`pre=0.08`）→ 闭爪 → 把篮子沿 x 拉 0.02、抬 0.05。
    - 成功：篮子相对初始抬升 > 2 cm、罐相对初始抬升 > 2 cm、篮子上轴与 z 点积 > 0.5、罐-篮 L1 距离 < 0.15、罐**离桌且接触篮子**。

27. **place_cans_plasticbox**
    - 动作：左臂抓左侧罐（x∈[-0.25,-0.15]）、右臂抓右侧罐（x∈[0.15,0.25]）→ 各抬 0.2 m → 左臂放罐到塑料盒 fp1、抬 0.08 并回原点，右臂再放罐到 fp0、抬 0.08。
    - 成功：每个罐到**最近**功能点的 xy 距离 < 0.04、双爪张开。
    - 注意：代码没有显式碰撞规划，"互不碰撞"靠时序错开。

28. **place_container_plate**
    - 动作：按容器侧选臂抓容器 → 抬 0.1 → 把容器功能点 0 对准盘子中心（`pre=0.12, dis=0.03` 释放）→ 抬 0.08 撤离。
    - 成功：位置每轴差 < 5/5/3 cm、双爪张开。

29. **place_dual_shoes**
    - 动作：左右臂各抓一只鞋 → 各抬 0.15；搬运中右臂额外做 x=0.1 / y=-0.05 平移并转成 top_down；两只鞋都对齐鞋盒姿态后放到盒内（沿 **y 方向 ±4 cm** 两个位置）。
    - 成功：左鞋 xy = 盒心 -[0,0.04]、右鞋 = 盒心 +[0,0.04]（容差 5 cm），两只鞋四元数都接近鞋盒四元数 [0.5,0.5,-0.5,-0.5]（各分量容差 0.07），z = 盒 z+0.01 ± 3 cm，双爪张开。
    - 注意：**没有"鞋尖朝左"约束**；代码只约束"两鞋同向且与鞋盒对齐"。

30. **place_empty_cup**
    - 动作：先预闭合爪到 0.6 → 抓杯（`pre=0.1`）→ 抬 0.08 → 把杯功能点 0 对准杯垫中心下降释放 → 抬 0.05 撤离。
    - 成功：杯 fp0 与杯垫 fp0 的 xy 距离 < 3.5 cm、`|Δz| < 1.5 cm`、双爪张开。
    - 注意：初版漏了"先预闭合爪到 0.6"；"补偿杯身倾斜"没有显式动作（只是 `align` 对齐）。

31. **place_fan**
    - 动作：按风扇侧选臂抓风扇顶面 → 抬 0.05 → 搬到颜色垫中心并对齐到固定目标姿态 [0.707,0.707,0,0] 后释放。
    - 成功：姿态接近该四元数（每分量容差 0.05）、位置每轴距垫中心 < 4 cm、双爪张开。
    - 注意：官方 instruction 原话 "make sure the fan is facing the robot"。

32. **place_mouse_pad**
    - 动作：抓鼠标 → 抬 0.1 → 搬到颜色垫中心并对齐后释放。
    - 成功：鼠标 xy 距垫中心 < 1.5 cm / 1.2 cm，且姿态满足 `|q2*q3-0.49|<0.015` 或 `|q0*q1-0.49|<0.015`（约 90° 朝向），双爪张开。
    - 注意：初版"垫子有效区域"过宽，实际是垫中心 1.5/1.2 cm；且漏了朝向约束。

33. **place_object_basket**
    - 动作：第一只手抓物体 → 抬 0.15 → 放入篮子（选较近功能点，`dis=0.02`，保持闭爪）→ 开爪释放、抬 0.08；第一只手回原点与第二只手抓篮子把手（`pre=0.08`）并发 → 把篮子移 ±0.05、抬 0.05。
    - 成功：篮子抬升 > 2 cm、物体抬升 > 2 cm、篮子保持竖直（轴·z > 0.5）、物-篮 L1 距离 < 0.15、物体接触篮子且不接触桌面。

34. **place_object_scale**
    - 动作：抓物体 → 抬 0.15 → 把物体支撑中心对准秤面功能点 0（`pre=0.05, dis=0.005` 释放）。
    - 成功：xy 距离 < 3.5 cm、物体 z 不低于秤面 z-1 cm、**仅抓取侧手爪**张开。

35. **place_object_stand**
    - 动作：按物体侧选臂抓物体 → 抬 0.06 → 把物体对准展示架功能点 0 释放。
    - 成功：物体 xy 与支架**本体 pose** 的 xy 每轴 < 3 cm、双爪张开；判据不查高度与姿态。

36. **place_phone_stand**
    - 动作：按手机侧选臂抓手机 → 把手机功能点 0 对齐到支架功能点 0（**托盘中心**），`dis=0` 后释放。
    - 成功：手机 fp0 与支架 fp0 三维差 < 4.5/4/4 cm、双爪张开。
    - 注意：官方功能点是"托盘中心"，**没有物理槽口**，也没有"插入"动作；旋转来自 `align`。

37. **place_shoe**
    - 动作：按鞋侧选臂抓鞋 → 抬 0.07 → 搬到**固定蓝色方块**（[0,-0.08,0.74]）并对齐到固定姿态 [0.5,0.5,-0.5,-0.5] 后释放。
    - 成功：鞋 xy 与 [0,-0.08] 差 < 5 cm / 2 cm、鞋四元数接近目标（每分量 < 0.07）、双爪张开。
    - 注意：目标是固定蓝块，不是随机颜色垫（与 31/32 不同）。

38. **press_stapler**
    - 动作：夹爪先从接触点上方约 22 cm 处闭爪 → 再沿接触点 -z 下压到上方约 14 cm 处（**行程 8 cm，不是 6.5 cm**），全程竖直向下。
    - 成功：夹爪与订书机 contact point 2 的 xy 差 < 3 cm、z 差 < 3 cm。
    - 注意：订书机 `is_static`，压下不会真闭合；"VLA 建立稳定接触"位置不对（闭爪在离上盖 22 cm 空中）；示范到按压即结束，不撤离。

39. **put_bottles_dustbin**
    - 动作：3 个瓶子，垃圾桶固定在桌面左侧（[-0.45,0,0]）。左半区瓶子由左臂直接投放；右半区瓶子先由右臂抓、放到中间位 [0,0,0.88]（保持闭爪）**交给左臂**（左臂闭爪后右臂松开），再由左臂搬到桶口 [-0.35,-0.1,0.93] 释放。
    - 成功：3 瓶 xy 与 [-0.45,0] 差 < 22.1 cm / 32.5 cm、z∈(0.2,0.7)（落进桶内）。
    - 注意：右侧瓶子在**机械上确实做了右臂→左臂换手**，初版"不是左右手交接"与代码矛盾；只是任务语义不要求交接。

40. **put_object_cabinet**
    - 动作：一只手抓住物体并保持；另一只手抓抽屉把手（`pre=0.05`）→ 沿抽屉轴（世界 y）拉 16 cm 打开抽屉 → 抬 0.15 → 把物体放到柜内功能点（`pre=0.13, dis=0.1`，靠下落进入）后释放。

    - 注意：判据不检查抽屉是否真的被拉开；开爪点离柜内功能点 10 cm。

41. **rotate_qrcode**
    - 动作：二维码牌在桌面随机位置、初始朝向绕 y 随机 ±0.7 rad（±40°）；按侧选臂抓牌 → 抬 0.07 → 搬到固定目标点 [±0.2,-0.15,0.74] 并对齐到固定姿态 [0.707,0.707,0,0] 后释放。

    - 注意：初版"约 146°"是**某一条示范的实测转动量**，不是固定规则（每回合初始朝向随机，实际转角会变）；也不是"放回原位"。

42. **scan_object**
    - 动作：双手分别抓扫描器和物体（`pre=0.08`）→ 两手同步调整（x=±0.05、z=0.13）→ 物体移到固定目标位、扫描器移到物体功能点 1 附近，**保持闭爪不释放**。
    - 成功：沿扫描器 -z 投影后偏差 < 2.5 cm、距离 ∈ (0, 0.07)、**双爪均闭合**。

43. **shake_bottle**
    - 动作：按瓶侧选臂抓瓶 → 抬 0.1 并转腕到 [0.707,0,0,0.707] → 重复 3 次：±5 cm 升降、腕部绕 y 交替 ±157.5° → 回到目标姿态。

44. **shake_bottle_horizontally**
    - 动作：抓瓶 → 抬 0.1 → **把瓶子转成水平姿态（绕 y 转 90°）** → 腕部绕 y 轴 ±157.5° 往复摆动，同时 z 方向 ±5 cm 起伏，约 3 个周期 → 回到目标姿态。
    - 成功：瓶心 z > 0.8。
    - 注意：**本任务不是"水平方向平移"**；初版"限制竖直漂移和手腕姿态变化"与代码相反（腕部峰峰值约 315°、竖直 ±5 cm）。

## 交接规则

只有 `handover_block` 和 `handover_mic` 属于**任务语义**上的左右手交接。五条判定条件不变：

1. 任务语义明确要求交接（官方 instruction 明确写 "handover"）；
2. 原持有手已经闭合；
3. 接收手随后闭合；
4. 两手存在共同持有区间；
5. 接收手闭合后，原持有手才松开。

**补充**：按"机械动作"看，`put_bottles_dustbin`（右侧瓶子）和 `dump_bin_bigbin`（右侧小箱）同样出现"一手抓→中间位→另一手抓→原手松开"的重叠换手；它们只是**任务语义不要求交接**。判定交接时应以"语义要求"为准，否则会把这些误判为 handover。

## 使用边界

- 示范中的世界坐标不直接进入运行时控制；接近参考帧需用当前 RGB-D 目标位姿转换到当前场景。
- **成功判据必须按官方 `check_success` 补全**：本版已为每条补上阈值；多数任务的判据末尾都包含"**双爪张开**"，另需注意 `open_laptop`（0.5 vs 0.4）与 `open_microwave`（0.7 vs 0.6）两处 `play_once` 目标值与 `check_success()` 默认值不一致。
- 闭爪事件只用于动作分段，不能单独证明抓取成功。
- 标注为"该条示范实测"的数值（如 `rotate_qrcode` 的 146°）不可当作固定规则复用。
- 官方任务是脚本化 demonstration；本文档描述的是"示范里实际发生什么 + 成功条件"，不是运行时逐字复刻的指令序列。
