# CAD 入镜比例软成本：独立选择器接入

本次只新增独立适配器和入口，不更改 `adapters/unified_vision` 的默认实现，不停止或覆盖其他实验。

## 规则

将静态 CAD 的顶点按候选位姿与相机标定投影到图像，计算投影凸包被图像矩形保留的面积比例 f。它是入镜比例近似，不是精确可见表面积、遮挡率或身份概率。模型与相机平面相交、投影退化时记 f=0，并施加有限软惩罚，不据此单独硬拒绝。

选择成本为 `原CAD几何成本 + 2 × (1-f)`。系数2在本轮200场评分前固定，不按任务、seed调整。CAD本来拒绝的候选不翻为通过；其他几何门槛、单目标0.15成本差门槛及一对一分配逻辑保持不变。该先验可能误伤真实的画面边缘目标，必须检查恢复和退化。

运行时适配器：`adapters/frustum_selection_v1.py` 中 `FrustumCadBackend`、`FrustumSelectionWorker`；worker独立入口 `scripts/run_frustum_selection_v1.py`。显式实例化新worker才启用；旧 `UnifiedVisionWorker` 不变。只重排每个候选原先最佳已接受CAD位姿，不重排其内部全部旋转假设。

## 固定候选200场对照

`scripts/replay_frustum_selection_v1.py` 读取原归档四任务全部50场：微波炉、笔记本、二维码、杯子/杯架。两组使用完全相同的保存候选、掩码、位置和已接受CAD位姿；不重新检测、SAM分割、补点或配准。对照组仅原几何成本，试验组仅额外入镜软成本。本轮不使用新包含关系合并、最大掩码代表或新的身份成本，避免混合改动。

两组选择都保存并哈希锁定后才读取独立标签评分；标签不传入选择器。候选去重均用原mask-IoU>0.5，场景分配均调用同一版本独占分配器。重新构造的固定候选对照不保证复现历史完整流水线，历史成绩单列；不能把历史与试验组的差异全部归为本次单因素收益。

位置沿用保存候选可见范围中心，不改成CAD原点。输出仅用于初始定位评测，明确不声称CAD朝向已消歧或操作位姿可用。模型使用凸包近似，对细架、镂空体不是精确轮廓；这项约束只针对模型大幅出画的解释漏洞，不能保证消除所有错误匹配。

结果：`results/frustum_fixed_200_20261112_v1/report.json`。原预测锁、传感器哈希和CAD文件核验保留；原实验文件不覆盖。相关9项单元测试通过；全项目回归日志 `results/frustum_selection_v1_tests_20261112.log` 以最终计数为准。

对照与历史归档最终通过状态逐场核对，200场无不一致。源码和输入哈希复核均未变化。全项目715项测试通过。

微波炉seed3由拒绝变为选择正确的microwave_04；其新成本约1.035，错误microwave_06约1.937。微波炉剩余失败seed43；二维码新增退化seed15，杯架新增退化seed47。新增退化未通过继续调参掩盖，默认任务入口没有替换。

这些是已知CAD、保存头部RGB-D与固定旧候选的开发集定位对照，非新场景盲测、非重新检测端到端评测、非完整机器人任务成功率，也未验证CAD朝向正确。2倍权重未在本轮结果后调整。
