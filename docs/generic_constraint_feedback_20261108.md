# 通用约束反馈与有限纠偏

## 可复用的部分

`adapters/constraint_feedback.py` 不依赖物体类别、颜色、长方块尺寸、任务名称、seed、机器人 API 或仿真评分。它接收抽象状态坐标、任务提供的允许区域、估计器提供的不确定性余量，输出四种决策：

1. `complete`：整个模型误差范围都在任务允许区域内。
2. `correct`：观测可用且存在留出误差余量的可行目标，计算目标后交给任务执行器规划。
3. `reobserve`：观测不可用，或不确定性大到任务区域无法容纳，暂不移动，要求重观测。
4. `stop`：重观测耗尽预算，或连续纠偏没有产生足够的观测改善。

支持不重叠坐标上的球形区域与区间/盒状区域的组合。这不是任意耦合约束求解器，不包含语义任务规划、碰撞规避、接触控制或自动感知建模。

球形允许区域会按径向误差余量收缩；区间会按估计误差收缩上下界。可行时，只有不满足的坐标才被修正，目标来自区域中心或任务提供的优选目标；没有写死“再移动多少毫米”。其他已经满足的坐标保留当前值，减少无关动作。

`FeedbackBudget` 在无量纲的约束违反量上检查进展，因此长度单位变化不改变其基本决策，也能用于角度坐标。进展阈值与重试次数仍为显式工程参数，不声称完全无超参数。

## 任务仍需提供的部分

任务适配器必须提供状态含义、允许范围、估计误差、阶段完成的含义和动作执行器。目标来自任务与感知，不从官方评分接口读取。纠偏动作仍须通过现有运动规划和实际到位检查。

- 放置：`adapters/support_placement_goal.py` 把物体局部支撑锚点、目标支撑面、水平容差和高度区间映射为通用约束。支持任意法向的几何坐标转换，不依赖杯子或方块类别。
- 开门：可把测得的门角度与期望角度范围交给同一约束决策器，但门转轴、把手轨迹与执行方式仍需开门任务适配器；目前只有合成角度闭环单元测试，未接入实际微波炉回归。
- 杯子与药瓶：可复用支撑目标接口，但当前未修改其现有执行路径。其感知、锚点估计和不确定性接口仍需单独接入验证。

当前 handover 的历史估计器仍依赖已知 6×6×20 cm 原始几何。把决策模块抽出来不等于整个感知框架已经适用于任意未知物体，也不代表已验证跨任务成功率。

## 本次 handover 接入

新入口为 `scripts/eval_pi05_handover_constraint.sh`。旧历史跟踪评测入口保留原逻辑，`adaptive_place` 只有显式传入 `feedback_goal` 才启用共享机制。

任务规范仍为水平偏差不超过 8 mm、释放间隙 3–18 mm、优选间隙 10 mm、原有倾斜要求，均未放宽。支撑锚点仍是方块局部底端中心。仅改变“估计均值已接近目标、考虑误差后仍超限”时立即停止的行为，改为按共享约束计算纠偏。

历史过期和既有不确定性质量要求保留；不增加试抬、物体仿真位姿或接触真值输入。当前 handover 估计器只报告世界 XY/Z 的模型余量，实际执行器明确拒绝把这些余量直接用于倾斜支撑面；倾斜面适配器应先投影完整协方差。

最大40轮整体反馈、每步25 mm平移/5°旋转等原任务动作预算保留。连续3次纠偏没有足够进展或2次额外重观测仍不可用会停止。重观测不会主动改变相机视角，因此同视角长期遮挡仍可能无法恢复。

估计器给出的模型误差范围不是经过校准的实际覆盖保证；位姿估计偏差、未观测滑动和不完整碰撞模型仍可能造成失败。

## 验证口径

新增共享模块测试包含：不同物体支撑锚点与容差、倾斜支撑平面、角度区间的合成闭环、单位尺度变化、不可行误差范围、进展停滞、有限重观测，以及原超限数值的集成回归。这些测试验证软件逻辑，不代替真实任务成功率。

完整任务先跑固定 seed 40026 起的5个有效随机场景，与已有结果配对比较。所有有效场景计入分母，场景初始化失败另计；交接真值不授权执行阶段。

```bash
cd /data1/xuhuixin/ula
GPU=7 HANDOVER_VISION_GPU=6 bash scripts/eval_pi05_handover_constraint.sh \
  --episodes 5 --seed 40026 \
  --output /data1/xuhuixin/ula/results/pi05_constraint_full_pilot5_seed40026_20261108_v1 \
  --detach
```

此为已分析种子的工程回归，不是未见场景泛化实验。结果以独立官方评分及完整五阶段成功条件为准。

## 本轮核对与补充验证

上述5场已有完整结果：5次交接成功、4次完整任务成功，官方评分也为4次成功。seed 40029 已经按共享规则继续纠偏，而非第一次发现误差范围超限就停止；其估计间隙约从17.21 mm变化到16.74 mm，后续为16.71、16.81、16.88 mm，未持续接近允许区域，因无进展停止，未松爪。此结果不说明纠偏一定能解决执行层或观测层的全部问题。

本轮保留已有实现，补充了任务适配器对刚体变换的验证，拒绝缩放、反射及非法齐次坐标；增加100组随机目标/尺度的目标可行性测试、多个独立角度坐标测试、整体坐标系旋转平移等价性测试和非法变换测试。完整测试478项通过，日志为 `results/generic_constraint_feedback_tests_20261108_v2.log`。

这些验证说明共享决策器不依赖特定方块尺寸、单位或世界坐标方向，不等于真实机器人已验证跨任务通用性；尚未改动或重测杯子、药瓶、微波炉的执行路径。
