# 点云实验：仅增加补观测与一次抓取恢复

本轮按要求只采用两项改动：截断观测时补充腕部视角、无抓取进展时有限恢复。
**不增加机器人区域过滤，不修改原点云过滤和 ICP 算法、质量阈值。**
旧完整 50 轮基线保留在 `results/pointcloud_full_50eps_20261024_190030/`，结果 45/50。

## 1. 截断观测的处理

新增 `--pointcloud-multiview`，默认关闭，保留旧流程。
SAM2 杯子掩码进入图像边缘 2 像素范围就标记观测截断，不能把可见范围直接声称为完整形状。

初始机械臂位置的腕部相机通常看不到杯子，所以先执行原粗接近并检查到位。
如果头部杯子掩码被截断且粗接近已到位，则：

1. 获取当前使用手臂的腕部 RGB-D，进行 cup-only 检测、分割和原点云几何估计。
   腕部看不到杯垫不构成错误；杯垫目标始终保留头部视觉估计。
2. 若腕部仍截断，利用相机外参和观测中心，计算一次相机图像平面内的居中平移。
   保持末端朝向，位移上限 10 cm，先规划、执行并检查实际末端到位。
3. 再观察一次；只接受不触及边缘、与头部桌面高度差 ≤2 cm 的腕部估计。
   仍无法获得完整腕部观测则拒绝交接，不假装已经补全。
4. 用腕部估计的杯子范围重新生成原点云接近目标，再执行并检查到位。

腕部观测只补充空间范围，不用它替换抓后配准的参考表面：

- 接近范围和支撑点 XY：腕部观测。
- 抓后跟踪参考点云：抓取前的头部观测。
- 桌面高度、杯垫目标：头部观测。

这样避免将腕部与头部看到的相反侧部分曲面直接当成同视角 ICP 对应关系。
选定的本轮参考另存为 `perception/selected_reference.npz`，原始头部输入/输出仍保留。
每个腕部请求也保存自己的 RGB-D 与估计结果。没有按机器人标签或颜色删点。

该策略仍只处理一种观测不足：掩码触及画面边缘。完全位于画面内的遮挡、分割混入机器人、
杯底不可见等问题不因此消失，不能将所有视觉异常都算作已解决。

## 2. 一次视觉授权的抓取恢复

新增 `--grasp-retries 1 --grasp-stall-steps 120`，默认重试次数为 0。
首次抓取超过 120 个动作仍没有达到原稳定抓取判据时，暂停在动作块边界进行视觉检查。
若首次检查未能确认安全支撑，可间隔 120 步再检查一次；最多两次检查。

视觉授权不读取杯子 actor 位姿或物理接触：重新获取头部 RGB-D，若被截断则尝试当前腕部视角。
需要连续两帧（间隔仿真 0.1 s）分别找到满足以下条件的观测：

- 杯子掩码未截断。
- 当前与参考桌面高度差 ≤15 mm。
- 可见最低范围相对桌面高度在 −3 至 +15 mm。
- 当前可见最高点相对抓前变化 ≤15 mm。
- 杯子范围中心 XY 相对抓前移动 ≤6 cm。
- 两帧范围中心漂移 ≤5 mm。

这些只是保守的视觉“仍支撑于桌面”启发式条件，不是接触或抓稳的严格证明。
看不清、疑似抬起、信息矛盾或检查失败，都不能授权张爪。

两帧均通过后才允许：张爪 → 世界 +Z 退回 8 cm → 新 RGB-D 感知和接近 → 再运行 VLA。
恢复最多一次；退回或重新接近失败立即停止。第二次抓取清空 VLA 动作缓存，重新创建抓稳监控器。
**不重置整轮 VLA 动作计数，不增加预算**，两次尝试合计仍最多 500 个动作。
放置使用重试后生成的本轮参考文件，不能错误沿用首次抓取参考。

原稳定抓取交接仍使用仿真杯子位姿和接触真值；只是“是否允许张爪恢复”的授权改用视觉。
最终任务成功评测仍使用 RoboTwin 真值。没有将系统描述成完全无真值。

## 3. 记录与耗时

新增记录：

- `handoff.multiview`：截断触发、各视角、居中移动、选定来源及是否解决。
- `grasp_attempts`：每次抓取的起止全局动作编号、动作数和结果。
- `visual_stall_checks`：各帧支撑证据、是否授权、漂移；失败也保留诊断。
- `recoveries`、`handoff_attempts`：恢复动作、重新到位与每次交接结果。
- `successes_without_grasp_retry`、`successes_after_grasp_retry`：批次成功数分开计。

补观测耗时记入传统接近；暂停 VLA 做的视觉检查记入 VLA 阶段；张爪、退回、重新接近
另计 `grasp_recovery`。总耗时包含全部检查、重试和失败，不只统计最后一次成功动作。

原相同 seeds 0–49 复测属于回归比较，不是陌生杯子或新场景泛化评测。
不把单独重测的失败 seeds 混入完整批次成功率。

## 4. 本次验证与运行

70 项测试通过，覆盖校准居中位移、补充视角不可替换杯垫目标、同视角跟踪参考、
无物体真值的支撑授权、抬起/截断时禁止恢复、缺授权禁止张爪，以及两次尝试共享 500 步预算。

单轮 seed 18 调试记录保留两版：第一版补观测后抓稳但跨视角放置失败；
第二版保持头部前后配准参考一致后完整成功。不能隐去第一版的失败。

冻结上述实现后运行完整 50 轮，不根据批次中途结果改参数：

```bash
cd /data1/xuhuixin/ula
GPU=5 bash scripts/run_place_empty_cup.sh \
  --mode hybrid --approach-mode pointcloud \
  --pointcloud-multiview --grasp-retries 1 --grasp-stall-steps 120 \
  --episodes 50 --seed 0 --max-vla-steps 500 \
  --output /data1/xuhuixin/ula/results/pointcloud_mv_retry_50eps_seed0_gpu5_v1
```

上面是本次已启动的输出目录，复现时换新目录，不覆盖已有结果。
最终成功率、恢复次数及时间应以批次结束后的 `report.json` 为准。
