# 七个抓后视觉拒绝样本的放宽对照

用户要求只对上一轮七个视觉失败样本放开限制测试，固定seed：40009、40024、40045、40051、40052、40053、40055。基线为 `results/pi05_constraint_initialfocus_full_50valid_seed40000_20261108_v1/report.json`，这七个样本原先均已通过交接核验、但在放置的第一次观测停止。

## 实验变更

单独入口 `scripts/eval_pi05_handover_relaxed_vision.sh`；原正式入口默认行为不变。

- 初次抓后观测的可见轴向跨度要求从7 cm降到3 cm，候选预筛与最终拟合同时配置，避免只改一个门槛。
- 多个长轴方向都能解释同一小块表面时，允许用机器人交接预测选取接近的解，并标记为预测选解，不声称朝向已被当前画面独立确定。
- 接受当前表面但完整位置不可观测时，允许临时初始化跟踪；隐藏长向坐标继承有条件的交接预测，给出15 mm长向模型标准差，预测选解的初始旋转标准差至少15°。
- 临时状态不能独自授权松爪，必须在后续获得独立完整位置测量及更大可见表面，且达到原置信范围后，才具备释放资格。

保留原4 mm点云RMSE门槛、6 mm内点比例、点数、任务运动预算、实际到位检查、通用纠偏规则和名义释放范围。不增加试抬，不使用对象真值或仿真身份像素进行控制。

这是放宽“初次视觉是否允许继续”的对照，不是删除全部观测和释放检查。若后续仍不能建立可信状态，会继续停止而不松爪。

## 验证与评测口径

完整491项测试通过。旧七个保存帧在实验配置下均可初始化；其中40009、40024、40045可得到完整位置，40051借助交接预测消解朝向歧义，40052、40053、40055以临时位置状态开始跟踪。该回放结果不能替代完整任务结果。

评测支持显式非连续seed清单，仅运行用户指定的七个场景。若有初始化失败只记录该seed，不额外挑选替代场景。左右手模型与其他控制参数保持不变，重新执行完整五阶段，独立记录初始定位、抓取、搬运、交接及最终官方评分，避免把继续执行当作最终成功。

```bash
cd /data1/xuhuixin/ula
GPU=0 HANDOVER_VISION_GPU=1 bash scripts/eval_pi05_handover_relaxed_vision.sh \
  --seeds 40009 40024 40045 40051 40052 40053 40055 \
  --output /data1/xuhuixin/ula/results/pi05_relaxed_vision_selected7_20261108_v1 \
  --detach
```

此为按旧失败结果挑出的诊断子集，不能用其成功率代表全部随机场景，也不能不经整批重跑就直接修改之前50次的总成功率。估计置信范围仍是工程模型，不是物理抓稳或未滑移的证明。
