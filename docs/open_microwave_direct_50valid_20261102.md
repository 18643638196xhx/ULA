# 微波炉直接拉门：50 个有效随机场景

## 本次到底测什么

沿用现有的无 CAD 微波炉 ULA：视觉寻找微波炉和把手，传统控制接近，VLA 完成局部闭爪，随后传统控制直接沿估计门轴分步拉门，直到视觉估计达到 70° 附近。抓后看不到把手时，使用新深度拟合可见门板；头部观测不可靠则尝试当前腕部画面。

微波炉原控制器没有杯子任务中那种额外向上试抬 5 cm 的动作。旧日志将第一次正常的 3° 开门增量叫作 `trial_pull`，但它与之后的开门增量没有额外动作上的区别。本次保留原名称方便审计，不额外试抬、不额外试拉，同时保留每一步开门后的视觉反馈。闭爪后保存视觉基准本身也不移动机器人。

因此，这是一轮现有控制器的重新评测，**不是取消某个原本存在的试抬动作的消融实验**，不能把与上一批的差异归因于“去掉试抬”。没有更改开门控制器或阈值，也没有更改杯子、药瓶的执行路径。

## 评测口径

使用 RoboTwin `demo_randomized` 场景配置和固定指令 `Open the microwave.`；不是官方完整 unseen 指令评测。由 seed 0 开始连续尝试，直到收集 50 个成功初始化的场景。初始化失败单独保存，并使用下一个连续 seed 补足；机器人开始执行后的感知、抓取、规划、开门失败全部计入这 50 次，不因方法失败补种子。

完整流程成功要求控制器正常完成，并通过控制结束后的官方评分。另列官方评分成功率，以区分“物理门已达到官方要求、但控制器最终视觉检查没有通过”的情况。成功率保留首个有效场景；成功完成平均时间剔除首个有效场景，只对之后成功完成的轮次取均值。

控制阶段不读取微波炉物体真值位姿、门关节角或物理接触。机器人自身状态、机器人模型与相机标定仍然需要；门轴来自初始视觉几何近似，而非读取仿真铰链。控制结束后才使用仿真门关节和官方评分进行评价。

GPU 7 运行主进程，GPU 6 运行视觉 worker，两者都是共享 GPU，没有算力隔离；采用 JAX platform allocator 降低常驻显存，不据此宣称耗时是独占硬件性能。

## 启动与进度

```bash
cd /data1/xuhuixin/ula
GPU=7 XLA_PYTHON_CLIENT_ALLOCATOR=platform \
MAX_JOBS=2 OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
bash scripts/run_open_microwave_direct_randomized.sh \
  --mode hybrid --episodes 50 --seed 0 --vision-gpu 6 \
  --approach-clearance 0.025 --approach-gripper 0.45 \
  --max-vla-steps 100 --target-angle-deg 70 \
  --output /data1/xuhuixin/ula/results/microwave_direct_randomized_50valid_seed0_20261102_v1 \
  > /data1/xuhuixin/ula/results/microwave_direct_randomized_50valid_seed0_20261102_v1.launcher.log 2>&1
```

输出目录必须为空；复现实验请更换目录，不能覆盖现有结果。日志中的 `[ula-microwave-direct] valid=.../50` 表示已完成的有效场景数。根目录 `report.json` 保存每轮结果、有效场景统计、初始化拒绝、源文件哈希、视觉进程状态；每轮目录保存初始、接近、闭爪和最终画面以及视觉点云与深度。

## 结果

已结束：`run_status=finished`，`completed_valid_episodes=50`。连续尝试 seeds 0–60，共 61 个原始场景；11 次初始化拒绝，补足后得到 50 次有效评测。拒绝 seeds 为 10、14、27、31、37、38、39、45、49、53、55，均不计入方法成功率分母。

| 指标 | 结果 |
| --- | --- |
| 完整流程成功率 | **66%（33/50）** |
| RoboTwin 官方评分成功率 | **72%（36/50）** |
| 成功完成平均时间，不含首个有效场景 | **23.776 s（32 个成功样本）** |
| 初始视觉定位失败 | 14 次 |
| 开门末段视觉检查失败 | 3 次 |

首个有效场景是 seed 0，成功率仍保留它；耗时排除它之后，33 个成功中有 32 个进入平均完成时间。计时包括环境设置、控制、最终评价和图像保存，不只是机器人运动时间。

14 次初始定位失败为 seeds 1、3、4、7、9、18、19、20、24、43、46、50、52、57。头部和腕部观测未给出通过检查的门/把手组合，这些轮次尚未进入 VLA 抓取。

另外 3 次是 seeds 5、23、28：都已执行 27 段正常开门动作，最后一次通过的视觉门角分别约为 66.71°、67.25°、67.06°；下一段动作后的头部和腕部画面都未通过门板跟踪，流程停止。这不是首次试拉失败，也不能说机器人完全没有拉开门——3 次在控制结束后的官方评分均为成功，因此官方评分比完整成功多 3 次。

所有实际进入开门的轮次，第一次开门步长均为 **3°**，没有额外向上的试抬或独立试拉动作。没有松开夹爪的失败恢复，也没有 VLA 接管开门的回退。

## 与上一批的关系

上一批 `microwave_panel_randomized_50eps_seed0_20261101_v4` 的 seeds 0–49 中，正常初始化 41 次，完整成功 25/41（61.0%）、官方成功 30/41（73.2%）。本批在这同一组 41 个有效场景上，完整成功 27/41（65.9%）、官方成功仍为 30/41（73.2%）；上一批 25 次完整成功全部保留，seeds 17、29 本次通过了末段视觉检查。

两批控制器与阈值相同，不能把这 2 次变化归因于“取消试抬”。seed 17 本次末段测得约 0.404° 增量，刚超过 0.4° 门槛；seed 29 在精细重观测后通过。它们也说明末段检查对观测和执行变化较敏感。这不是逐动作完全相同的严格配对实验，也没有隔离共享 GPU 负载。

本批补充的 seeds 50–60 中有 9 个有效场景，成功 6 次，因此整批为 33/50。不要直接用新的 50 个有效场景与旧的“50 个原始尝试”混用分母。

## 时间分解与一致性

下面各项均取同一组 32 个稳态成功样本的平均值：

| 阶段 | 平均耗时 |
| --- | --- |
| 环境设置 | 0.362 s |
| 初始感知与传统接近 | 14.340 s |
| VLA 局部闭爪 | 0.493 s |
| 闭爪后视觉基准 | 0.068 s |
| 传统分步拉门及视觉反馈 | 7.478 s |
| 保存图像等 | 1.035 s |
| 总计，含微小评价与计时差 | **23.776 s** |

接近阶段的规划查询平均累计 13.371 s，平均 6.469 次，因此主要耗时仍在传统接近规划，而非 VLA 推理。

321 项 CPU 回归通过。视觉进程全程启动一次，结束后 `closed=true`、`running=false`；抓后门板跟踪在主进程处理，不属于视觉 worker 的初始识别请求。`randomized_sources_unchanged=true`、`placement_files_unchanged_during_run=true`。主进程已退出；退出码 1 表示批次包含失败轮次，不表示未跑完。

完整数据在 `results/microwave_direct_randomized_50valid_seed0_20261102_v1/report.json`。可以运行 `scripts/summarize_microwave_direct.py` 读取报告和共同场景对比；旧输出没有覆盖。
