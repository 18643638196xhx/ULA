# 随机微波炉：整机定位与抓后门板跟踪

## 为什么改

上批 `microwave_randomized_50eps_seed0_20261101_v1` 连续 seeds 0–49，完整成功和官方评分均 8/50（16%）；9 次初始化失败，正常启动的 41 次中成功 8/41（19.5%）。16 次停在初始视觉，14 次停在闭爪后基准，3 次停在传统试拉或开门后的视觉检查。

本次实现用户同意的两个变化：先找整机再用实测深度找门/把手；夹爪遮挡把手后优先追踪可见门板，而不是反复要求看清把手。没有修改杯子、药瓶、原微波炉控制/感知文件，也没有使用微波炉 CAD 或在线物体真值。

## 方法和证据边界

初始阶段用原 Grounding DINO 检测整台微波炉（普通/精细尝试使用有限的整机提示），至多取三个整机框，在框内的当前仿真相机 RGB-D 深度寻找竖直门面层与突出把手。仍经过原平面支持、尺寸、竖直把手形状及对侧门轴关系检查；不同框若对应明显不同把手则拒绝。整机路径不可靠时保留原门语义识别分支，不用固定图像区域或真值位置兜底。

初始门板、把手、对侧边缘门轴和可见矩形范围通过检查后保存。门轴仍是“竖直、位于把手对侧门边”的近似，不是直接观测隐藏铰链。

抓后仅在初始矩形按当前估计刚性更新后的范围内，从新深度重新拟合门面。命令预测只扩展“到哪里找”的范围，搜索同时保留未移动位置，不能让命令强迫返回对应转角。使用固定初始范围，不逐步吸入机身、夹爪或背景。没有机器人像素身份过滤，也不主动移动机器人换视角；头部深度不可靠时尝试当前左腕相机。

跟踪仍要求至少 80 个当前深度点、二维可见面、平面残差约 3 mm 内、与初始视觉门轴的刚性平面偏差不超过 15 mm、可见范围面积为初始范围的 20%–140%。原门面拟合的最小宽高 8 cm 仍保留；不是任意一小条边都能通过。只对初始实测范围内当前可见面拟合，隐藏部分没有被直接测量。

**看不见把手时的 `handle_world` 是推算锚点：用新深度实测门面转角，把初始视觉把手锚点绕估计门轴旋转。它不是当前测得的把手，更不能当成独立的“把手随动证据”。** 每帧审计明确 `handle_measured=false`、`hidden_handle_anchor_inferred=true`。

因此本次明确替换了抓后证据：不再要求“新测门面旋转 + 独立新测把手随动”，改为“当前门面确实旋转 + 当前深度支持 + 平面残差/刚性关系/固定范围一致”。每步 3° 时仍要求新测角度增量至少 0.6°、不超过 6.5°，静止或反向门不能通过。它是新的视觉启发式，不是力传感或物理抓稳证明；错误初始门轴、局部面混淆、静止机身抢占等仍可能导致偏差或停止。

仍先用机器人编码器/TCP 检查动作到位，再检查实际视觉；没有新深度就停止，不继续拉、不主动松爪、不让 VLA 代替开门。闭爪前后门转动超过 3° 仍拒绝 VLA 开门角色泄漏。目标 70° 的既有 1° 收敛范围保留，最终还需通过官方评分。

## 验证与开发记录

CPU 合成验证覆盖：把手完全不可见而门面确实转动可通过；给静止门输入旋转命令也不能通过；缺深度、只有前景遮挡、反向转动拒绝；固定初始范围不增长；头部失败可切腕部且不调用物体真值；整机框加深度可初始化；独立入口恢复原函数。

保存数据的 CPU 离线回放 `microwave_panel_replay_20261101_v1` 中，上批 14 个抓后失败场景均恢复门面基准，测得角度接近初始状态。**14/14 是原帧可用性，不是任务成功率，也不证明夹持可靠。**

首轮 4 次接入测试 `microwave_panel_pilot4_seed0_20261101_v2` 因视觉 worker 的同名 `scripts` 包冲突而未正常加载；全部记录保留，不作为算法成功率。修复为显式文件路径加载协议并补测试后，实际先导 `microwave_panel_pilot4_seed0_20261101_v3` 为 2/4：0、2 完整成功，1、3 初始定位仍失败。该组先导种子上旧随机化方案为 0/4；小样本开发结果不能替代正式评测。

正式版与有效先导的算法和阈值相同，另补充了初始失败的完整诊断与开门错误文字，明确不再将新门板分支报成独立把手随动检查。

## 冻结后的 50 次评测

正式目录：`results/microwave_panel_randomized_50eps_seed0_20261101_v4`；同名前缀 `.launcher.log` 保存完整日志。独立入口为 `scripts/run_open_microwave_panel_randomized.py` 和 `.sh`；原 runner、随机化旧入口和现有任务文件不变。报告逐轮保存随机化实际配置、证据变化、源文件哈希及完整/官方/初始化后三种统计口径。

```bash
cd /data1/xuhuixin/ula
GPU=7 MICROWAVE_JAX_FRACTION=0.40 \
MICROWAVE_MAIN_TORCH_FRACTION=0.08 MICROWAVE_VISION_MEMORY_FRACTION=0.10 \
MAX_JOBS=2 OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 \
bash scripts/run_open_microwave_panel_randomized.sh \
  --mode hybrid --episodes 50 --seed 0 \
  --approach-clearance 0.025 --approach-gripper 0.45 \
  --max-vla-steps 100 --target-angle-deg 70 \
  --output /data1/xuhuixin/ula/results/microwave_panel_randomized_50eps_seed0_20261101_v4
```

与上批同为官方 `demo_randomized` 场景设置、固定指令、两种任务原始微波炉型号、连续原始 seeds 0–49、同卡 GPU7 共享及相同动作模型。不是官方 unseen 指令采样，也不是单独门板跟踪消融，因为初始定位分支同时改变。初始化失败保留，不补种子。耗时只对成功样本取均值并剔除第一轮，共享负载下不将均时差全部归因于算法。

## 正式结果：50/50 已结束

`run_status=finished`，连续原始 seeds 0–49 全部保留。视觉进程启动一次，80 次初始识别请求中 31 次正常返回；抓后门板跟踪在主进程处理，不计入这个 worker 请求数。视觉进程已正常关闭，主进程已退出。退出码 1 表示批次存在失败轮，并非只运行了部分轮次。

| 指标 | 上一批随机化 v1 | 本次新方案 v4 |
| --- | --- | --- |
| 全部尝试的完整成功率 | 16%（8/50） | **50%（25/50）** |
| 全部尝试的官方评分成功率 | 16%（8/50） | **60%（30/50）** |
| 场景初始化失败 | 9 | 9（相同种子） |
| 正常初始化后的完整成功率 | 19.5%（8/41） | **61.0%（25/41）** |
| 正常初始化后的官方成功率 | 19.5%（8/41） | **73.2%（30/41）** |
| 成功完成均时，不含第一轮 | 16.996 s（8 个样本） | **23.448 s（24 个样本）** |

成功率的分母不剔除首轮；仅耗时剔除第一轮。新方案首轮 seed 0 成功且含模型加载，因此 25 次完整成功中有 24 次进入稳态完成均时。剔除首轮后的全部尝试均时为 15.050 s（49 个样本），不可称为成功完成时间。

原 8 个成功种子均保留成功，没有从完整成功退化为失败的种子；新增 17 个完整成功：0、2、6、13、15、16、22、25、26、30、32、34、40、41、42、47、48。两批是同一组随机场景的一次前后对照，不据此承诺未来稳定成功率。

### 改善发生在哪里

| 终止阶段 | 上批 | 本批 |
| --- | --- | --- |
| 环境初始化 | 9 | 9 |
| 初始定位 | 16 | 11 |
| 抓后基准观测 | 14 | **0** |
| 传统开门后的视觉验证 | 3 | 5 |

本次 30 次通过初始定位的场景，全部通过抓后门板基准；其中 23 次初始定位使用整机框加深度分支，7 次使用原门语义回退。原初始失败中的 23、29、30、40、41 得到可用初始定位，其中 30、40、41 完整成功，23、29 达到官方评分但未通过最后视觉验证。

这不是说“所有把手都被重新看清”，而是新分支不再要求遮挡后的完整把手，改用通过几何检查的当前门板。由于初始定位和抓后证据同时变化，阶段统计不等于严格的单因素收益归因。

### 剩余失败的具体原因

| 类型 | seed | 说明 |
| --- | --- | --- |
| 初始化失败（9） | 10、14、27、31、37、38、39、45、49 | 与上批相同的杂物稳定性拒绝，控制尚未开始 |
| 初始视觉失败（11） | 1、3、4、7、9、18、19、20、24、43、46 | 头部与腕部的整机/门区域及深度几何没有返回可信组合 |
| 后段观测丢失（3） | 5、23、28 | 最后通过的视觉角约 66.76°、67.27°、67.09°；下一段动作后两个视角都未通过当前门板拟合 |
| 收尾小增量门槛（2） | 17、29 | 新视觉角已经约 69.11°、69.31°，但单步增量约 0.240°、0.374°，低于保留的 0.4° 最小增量，仍被拒绝 |

最后这 5 次都通过了控制结束后的官方评分，但没有完整通过新流程，仍计作完整失败。尤其 17、29 不是“完全看不到门”，而是视觉可测、最终角度已进入既有终点范围，却未过单步增量检查；本批没有临时取消该门槛或把它们手动改成成功。

控制结束后的仿真门关节诊断约为：5 为 69.14°、17 为 69.28°、23 为 69.50°、28 为 69.40°、29 为 69.53°。这些仅用于解释终态，未回传给控制器继续动作或修改成功记录。

### 成功样本耗时分解

以下为相同 24 个稳态成功样本，阶段互不重叠：

| 阶段 | 平均时间 |
| --- | --- |
| 环境设置 | 0.373 s |
| 传统接近，含初始感知 | **14.064 s** |
| VLA 局部闭爪 | 0.496 s |
| 抓后门板基准 | 0.069 s |
| 传统试拉和连续开门 | 7.399 s |
| 保存图像等 | 1.047 s |
| 总计，含微小计时差 | **23.448 s** |

接近阶段的规划查询平均累计 13.022 s、平均 6.417 次查询；初始感知平均约 0.388 s。因而本批较长时间主要在接近规划，不在 VLA 推理或门板基准。

新成功样本包含旧方案无法完成的场景，不能直接把 16.996→23.448 s 当成同一场景的算法变慢。对共同成功的 8 个种子配对，旧均时 16.996 s，新均时 18.851 s；同样不能排除共享 GPU 负载和不同初始几何引起的规划差异。本次主要验证可靠性改善，并未实现加速。

### 一致性与结论

`randomized_sources_unchanged=true`，`placement_files_unchanged_during_run=true`。本批结束后重新核对旧 v1 报告记录的所有原有源码，均未改变；新分支及入口的当前哈希也与本批启动时一致。没有修改杯子或药瓶任务，没有覆盖原微波炉路径、旧输出或失败样本。

结论：这次改动使完整成功 8→25、官方成功 8→30，主要消除了抓后必须重识别完整把手的停机，并改善部分初始定位。剩余重点为 11 次初始定位以及接近终点时的可观测性/小增量验证；没有宣称所有问题解决或已适配真实硬件。
