## 实验定义

预先指定 RoboTwin 的 044_microwave / 7167 型号、0.15 模型尺度及 URDF 门轴结构，并在实验场景中生成同一型号。型号是实验前明确提供的条件，不是在线读取物体型号后挑选 CAD。模型来自仿真资产，属于理想已知模型设置，不是实物扫描重建或未知型号识别。

仅组装 URDF 中可动门部件的网格，在门轴局部坐标系中做 FoundationPose 注册；不把会开合的整台微波炉当成始终刚性的单个对象。DINO/SAM 与深度几何提供门的可见区域，FoundationPose 用 RGB-D 估计门部件位姿，没有仿真物体位姿初值。

由视觉估计的门位姿变换 CAD 把手前表面锚点和门轴位置，用它们计算传统接近与圆弧运动。仍保留竖直门轴假设，并检查估计门轴是否接近竖直、模型正面是否与实测门面一致、模型把手是否接近当前深度把手。门轴不再由可见门边位置近似推算。

之后仍是 ULA 分工：传统接近 → WorldLA 对准闭爪 → 闭爪后视觉基准 → 传统首次试拉和逐步开门。后续主要使用新鲜 RGB-D 门面/把手跟踪，不是每步都运行 FoundationPose；检测回退需要时才会再次调用已知模型感知。保留原有 70° 目标、1° 收敛范围和随动门槛，不因单次结果改判定。

在线控制不读取微波炉真实位姿、门关节或接触信息；仍使用仿真 RGB-D、机器人状态和相机标定。原始成功评分与真实最终门角仅在控制停止后读取。
